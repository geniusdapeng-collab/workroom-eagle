# 企业深度诊断

## 适用场景
- 诊断期/体检期客户的资料准备、数据治理与诊断分析
- 多框架（7S/五力/SWOT/BLM）素材组装
- 结论素材包产出：证据钉死，定调留给人（含结论内容外发必审，C-R2）

## 方法
1. 资料清单与催收：按诊断范围开出资料清单（近 3 年报表、组织架构、核心流程文档、
   关键经营指标、既有制度），标注每份的用途与到位期限；催收节奏为「发出→3 天提醒→
   逾期升级主理人」，到位情况实时入档。
2. 数据清洗口径：统一会计期间、币种、合并范围与科目口径；清洗规则（剔除项、调整项）
   逐条记录，保证任何人按规则可复现同一结果。口径变更必须留痕并注明理由。
3. 勾稽校验三向互证：
   - 报表互证：资产负债表/利润表/现金流量表之间勾稽，明细与总额核对
   - 数访互证：报表数字与访谈陈述交叉验证，冲突处进矛盾点清单
   - 前后互证：跨期数据的趋势合理性检验，突变必须找到解释或标「未核实」
   校验不过的口径不得静默修正，列出差异、量级与可能原因供主理人判断。
4. 框架选用：按议题选框架，不为凑框架而框架——
   组织效能议题用 7S；竞争与议价议题用五力；战略盘点用 SWOT；
   从战略到执行的全链条议题用 BLM。每个框架模块填充时注明素材出处。
5. 结论素材包组装：候选结论逐条挂证据链（数据出处 + 访谈出处 + 案例参照），
   并附红队反证意见；素材包交主理人定调，AI 不输出「最终诊断结论」。

## 输出契约
- 资料清单：项目/用途/期限/到位状态四列，催收记录可溯。
- 清洗报告：口径规则清单 + 勾稽校验结果（通过项与差异项），差异项附可能原因。
- 结论素材包：每个候选结论 = 结论陈述 + 证据链 + 数据出处 + 红队反证，定调位置留白。
- 关键数字必须来自工具回执或客户盖章资料；无回执标「未核实」且不得进入结论素材。
- 含结论、人员评价、组织建议的内容一律挂起待审（C-R2），AI 不擅自外发。
