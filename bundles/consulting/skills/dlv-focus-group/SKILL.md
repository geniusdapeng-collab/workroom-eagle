# 焦点小组主持

## 适用场景
- 员工满意度、文化诊断等需要群体视角的议题
- 方案宣贯前的意见预演与阻力探测
- 客户/用户对新产品、新流程的集体反馈采集

## 方法
1. 组员搭配：6-8 人，同层级不同部门混编；上下级不同组，
   利益冲突方（如考核双方）不同组；每组设 1 名「观点差异者」防止一团和气。
2. 议题梯度设计：按「热身（事实类）→ 观点（评价类）→ 敏感（建议类）」
   三段递进，每段 1-2 个议题；敏感议题放后段，待信任建立后再切入。
3. 主持控场三原则：
   - 先写后说：关键议题先独立写便签再轮流发言，切断首因效应
   - 轮值发言：每人必须发言，主持人不点评只追问
   - 异见保护：出现少数派观点时明确「这个角度很重要，展开说说」
4. 从众压力化解：发现附和信号（重复他人措辞、看领导脸色）时，
   立即切换匿名投票或书面补充；会后可单独回访沉默者。
5. 记录与收敛：全程双记录（内容 + 互动动力学），
   收尾用「共识点 / 分歧点 / 意外发现」三框现场收敛并请组员确认。

## 输出契约
- 小组纪要：共识点 / 分歧点 / 意外发现三框，分歧点保留各方原话不合并。
- 互动动力学观察：谁主导、谁沉默、谁附和，仅作背景供人类顾问解读。
- 结论按「组内一致性强度」分级，单组结论不得直接升级为组织级结论。
- 涉及个人评价的内容匿名化处理，是否可引用由人类判断。
