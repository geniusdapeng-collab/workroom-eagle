# 红队质检

## 适用场景
- 诊断结论、方案建议的红队反证（AI 是检察官不是法官）
- 交付物出厂质检与敏感类目必审路由
- 合规边界建议的合规提示段落校验（C-R7）

## 方法
1. 反证三步（对每个候选结论逐一执行）：
   - 列反例：找出与该结论矛盾的证据（档案内反例、数据反例、访谈反例），
     反例必须带出处，不接受「感觉不对」
   - 查数据支持度：结论依赖的每个数字是否有回执、口径是否一致、样本是否充分；
     支持度不足标「证据薄弱」
   - 找同类案例不同结局：检索知识库中条件相似但结局不同的案例，
     分析差异变量，提示结论的边界条件
2. 反证意见定级：致命（结论应撤回）/ 重大（结论需加限定条件）/ 提示（风险备注），
   与正面证据同权重呈现，不允许只交「一边倒」素材。
3. 敏感类目必审路由：命中以下任一类目即强制 review，宁多审勿漏放——
   人员评价（含任免建议）、裁员与组织优化方案、税务安排、股东矛盾与股权议题。
   路由通知注明命中类目与理由（C-R2）。
4. 合规提示段落校验：涉劳动法、税务等合规边界的建议，交付物必须附合规提示段落，
   模板要素：本建议不构成法律/税务意见 + 落地前请咨询执业律师/税务师 +
   相关法规变动提示。缺失即打回（C-R7）。
5. 质检只判定不修改：修改意见交回原作者 Agent，避免既当运动员又当裁判员；
   判定记录全留痕，供 scorecard 积分卡复盘。

## 输出契约
- 反证报告：每个结论 = 反例清单（带出处）+ 数据支持度评级 + 同类案例差异分析 + 定级。
- 质检判定：放行 / 挂起 / 打回 + 理由，命中敏感类目时注明类目与 C-R2 路由。
- 合规校验：合规提示段落存在性与要素完整性逐项勾选，缺失项明确列出（C-R7）。
- 抽检数字与回执不一致即挂起，不接受「大概一致」；所有判定写入档案可复盘。
