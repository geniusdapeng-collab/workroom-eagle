# 质量管理体系

## 适用场景
- 客诉与退货率高，质量靠「事后救火」
- 来料问题频发，与供应商互相扯皮
- 客户审厂或体系认证（ISO9001/IATF16949）前准备

## 方法
1. 质量现状诊断：用质量成本（COQ）四分法透视——
   预防 / 鉴定 / 内部损失 / 外部损失，
   多数企业外部损失被低估，用客诉与退货数据挂回执显化。
2. 来料控制（IQC）：按物料风险分级定检验策略
   （全检 / 抽检 / 免验），抽检方案用 GB/T 2828.1 计数抽样标准；
   供应商来料绩效与分级管理联动。
3. 过程控制（IPQC）：关键工序识别（CCP/CTQ），
   控制计划三要素——检验项目 / 频次 / 反应计划；
   推行「三不原则」（不接受 / 不制造 / 不流出不良）与
   防错法（Poka-Yoke）替代人工目检。
4. 出厂控制（OQC）与追溯：成品检验标准与客户标准对齐；
   建立批次追溯体系（正向：批次→客户；反向：客诉→批次→
   工序→物料），追溯演练记录存档。
5. 客诉闭环：8D 报告标准化——团队 / 问题描述 / 临时围堵 /
   根因（5Why+鱼骨）/ 永久对策 / 验证 / 防再发 / 表彰，
   D3 围堵时限与 D5 根因验证强制化。
6. 质量例会机制：周质量会（top 问题跟进）+ 月质量经营会
   （COQ 趋势与质量 KPI），输出会议模板。

## 输出契约
- 质量体系方案：COQ 诊断报告 + 三段控制计划（IQC/IPQC/OQC）
  + 追溯体系设计 + 8D 模板与例会机制。
- 检验标准与抽样方案注明引用标准条款。
- 客诉与不良数据挂系统回执；根因分析区分「事实 / 推断」。
- 涉及供应商索赔与质量责任判定的争议事项，
  提示商务与法务介入（C-R7），AI 不作责任裁定。
