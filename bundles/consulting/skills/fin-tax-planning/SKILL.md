# 税务筹划合规

## 适用场景
- 税负明显偏高，需合法优化业务架构
- 优惠政策不知道、不会用、不敢用
- 历史财税处理存在瑕疵，需风险排查
- 股权/分红/薪酬结构的税负优化

## 方法
1. 税负现状体检：计算综合税负率 = 实际缴纳各项税费合计 / 营收，
   分税种（增值税/企业所得税/个税）与行业均值对比，找出偏离最大的税种；
   数据全部挂纳税申报表回执。
2. 优惠政策适配：逐项核对可适用的政策（小规模纳税人/小微企业所得税优惠/
   研发加计扣除/高新技术企业 15%/区域性政策），
   每个政策列出适用条件、留存备查材料与测算节税额。
3. 业务架构优化：从「业务模式/主体架构/交易路径」三层审视——
   如业务拆分适用不同税率、主体选址匹配政策、合同条款影响纳税时点；
   方案必须有真实商业目的，杜绝无实质的「避税安排」。
4. 风险边界把控：红线清单——虚开发票、阴阳合同、私户收款、
   变名开票一律禁止；灰色事项标注风险等级并建议取得专业书面意见。
5. 合规提示与路由：所有涉税方案必须附合规提示段落
   （不构成税务意见 + 落地前咨询执业税务师 + 政策变动提示），
   税务安排命中敏感类目，一律必审（C-R2）并绑定 C-R7 合规校验。

## 输出契约
- 税负体检表：分税种税负率 + 行业对比 + 申报表回执。
- 优惠政策适配清单：条件/备查材料/测算节税额/适用判定。
- 架构优化方案：商业目的说明 + 节税测算 + 实施步骤。
- 风险边界清单：红线事项 + 灰色事项风险分级。
- 全部方案附合规提示段落（C-R7），涉税内容必审（C-R2），最终方案由执业税务师把关。
