# 平台化战略

## 适用场景
- 企业从自营业务向平台模式转型
- 双边/多边市场从 0 到 1 冷启动
- 已有平台但增长停滞或治理失序

## 方法
1. 平台适配性诊断：确认业务具备平台基因——
   供需两端碎片化 / 匹配成本高 / 交易频次足够 /
   平台方能提供超越中介的信任或效率价值；四缺二即劝退。
2. 双边结构定义：明确补贴方与被补贴方（通常补贴价格敏感、
   能带来网络效应的一方），定义核心交互单元
   （参与者 + 价值单元 + 过滤器三要素）。
3. 冷启动设计：五选一或组合——单边突破（先做工具再开放）/
   种子供给自营 / 大客户锚定 / 地理或品类聚焦打透 /
   借力已有流量池；写明所选策略的密度目标
   （如：单城市供给密度 ≥ X 才开下一城）。
4. 网络效应设计：区分同边 / 跨边 / 数据网络效应，
   为每类设计增强回路并定义度量指标（如匹配率、跨边转化率）；
   同时列出负网络效应（拥堵、劣币驱逐）的预防机制。
5. 补贴与定价策略：设计补贴递减曲线与退出条件，
   明确「补贴买的是密度与习惯，不是交易额」，
   设定单位经济模型转正的硬性时限。
6. 治理规则框架：准入 / 行为规范 / 争议仲裁 / 退出四模块，
   规则先于规模建立；涉及对商家的处罚与清退规则
   须审合同与法律依据（C-R7）。

## 输出契约
- 平台战略蓝图：适配性诊断 + 双边结构定义 + 冷启动策略（带密度目标）。
- 网络效应度量指标表与负效应预防清单。
- 补贴递减方案与 UE 转正时限，关键假设逐条列明。
- 平台治理规则草案附合规提示（不构成法律意见，上线前律师审，C-R7）；
  涉及商家/用户数据使用规则按 C-R5 脱敏与授权前置。
