# 业务组合管理

## 适用场景
- 多业务企业资源分散，需要做取舍聚焦
- 某业务持续亏损，需评估保留 / 整改 / 退出
- 集团化后总部需建立业务组合管控机制

## 方法
1. 业务单元切分：按「独立客户群 / 独立价值链 / 可单独核算」
   三标准切分 SBU，切分不清的矩阵分析无意义；
   收集各单元近三年收入、毛利、现金流、市占数据并挂回执。
2. BCG 矩阵初判：以相对市场份额 × 市场增长率定位
   明星 / 金牛 / 问题 / 瘦狗四象限，明确标注分界线的取值依据，
   避免用「感觉」划线。
3. GE 矩阵校准：用「行业吸引力 × 竞争地位」九宮格复核，
   两矩阵结论冲突时以 GE 为准并分析差异原因
   （通常是份额口径或细分边界问题）。
4. 取舍建议生成：按象限给出标准策略——明星加投 / 金牛收割 /
   问题业务「加码或退出」二选一 / 瘦狗退出或利基化；
   每个建议附财务影响测算（收入 / 利润 / 现金流 / 人员）。
5. 资源再配置方案：把收割业务释放的资源明确指向加投业务，
   输出「资源从哪来、到哪去」对照表，防止只砍不投。
6. 退出路径设计：对退出类业务给出关停 / 出售 / 分拆三路径比较，
   含员工安置、合同义务、品牌影响清单。

## 输出契约
- 组合诊断报告：SBU 切分依据 + 双矩阵定位图 + 数据回执清单。
- 取舍建议表：每业务 = 定位 + 策略 + 财务影响测算。
- 涉及业务关停、人员安置的建议触发必审路由（C-R2/C-R7），
  并附合规提示（本建议不构成法律意见，落地前咨询执业律师）。
- 最终取舍决策权在客户董事会，AI 只提供选项与测算，不替客户拍板。
