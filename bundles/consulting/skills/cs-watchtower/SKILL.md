# 预警值守服务

## 适用场景
- 常年顾问合约中的红线值守模块（现金流、舆情、关键指标）
- 客户经营高风险期（扩张、转型、换帅）的加强值守
- 作为独立高溢价产品销售的风险兜底服务

## 方法
1. 红线共定：与客户老板共同定义红线清单，每条红线 =
   指标 + 阈值 + 数据源 + 检查频率 + 通知人——
   现金流红线（可用资金 < N 个月固定开支）、
   经营红线（核心指标连续 N 期破阈值）、
   舆情红线（负面信息出现并达传播阈值）、
   人事红线（关键岗位异动信号）；红线清单客户签字，季度重签。
2. 值守节拍：数据类红线按日自动扫描（接月报同源数据），
   舆情类按日巡检，重大政策即时接入情报订阅的即时级通道；
   每次扫描留痕（时间、结果、是否触线），构成值守台账。
3. 触线响应三步：
   - 核实：先排除数据故障与口径变化，防止狼来了
   - 分级：黄线（触线但可解释）记入月报 / 红线（确认触线）
     2 小时内电话 + 书面双通道通知指定人
   - 陪议：红线触发后 24 小时内提供「归因初判 + 选项清单」，
     选项含代价对比，决策留给客户
4. 值守证明：每月出值守月报（扫描次数、触线次数、响应时效、
   误报次数）——没有触线的月份，值守证明本身就是价值呈现，
   是年度价值报告中「期权价值」的记账依据。
5. 误报治理：误报逐条归因（阈值问题/数据问题/口径问题），
   误报率 >10% 的红线回炉重定阈值；连续 3 个月零触线的红线
   与客户确认是否保留，防清单虚化。
6. 边界声明：值守只负责「及时发现 + 呈现选项」，
   经营决策与执行责任永远在客户侧，服务协议中写明。

## 输出契约
- 红线清单：五要素齐备、客户签字、季度重签记录。
- 值守台账：每次扫描留痕 + 触线事件的全流程记录（核实/分级/通知/陪议）。
- 值守月报：含零触线月份的值守证明，直接挂接价值台账。
- 触线后的行动决策由客户做出；红线定义与通知范围的变更必须客户确认。
