# 高管教练支持

## 适用场景
- 客户老板/高管重大决策前的陪议（投资、任免、转型）
- 重要场合（董事会、融资路演、全员会）的议题预演
- 常年顾问服务中的高管一对一深度支持

## 方法
1. 陪议边界先行：教练的角色是「让客户自己想清楚」，
   不是替客户做决定；首次陪议即声明——
   只问不判（用问题暴露盲区）、给选项不给答案、
   决策与后果永远属于客户本人。
2. 决策陪议四步：
   - 澄清决策：把「要不要做 X」改写为可检验的决策句
     （「在 A 与 B 之间，按什么标准选」）
   - 穷举选项：强制列出 ≥3 个选项（含「不做」），
     每个选项写最好/最差/最可能三种结局
   - 压力测试：对每个选项问「什么情况下这会是个错误」，
     反方意见优先呈现
   - 收口承诺：客户自己说出决定、理由与检视时间点，记入陪议纪要
3. 议题预演：重要场合前做一次全流程彩排——
   立场地图（谁会反对）→ 三大尖锐提问模拟 → 回答演练 →
   时间控制演练；预演录像或速记供客户回看。
4. 问答预案库：围绕高频场景（董事会、投资人、媒体）建问答库，
   每问配「核心回答 + 数据支撑 + 禁说清单」；
   数字一律挂已核口径，预演中禁止即兴报数。
5. 教练档案：每位高管的决策风格、盲区清单、历史陪议纪要归档；
   新议题先调档案，避免重复踩同一个坑。
6. 保密纪律：陪议内容默认不向客户公司内其他人披露，
   含老板本人要求传达的内容也建议由其本人传达。

## 输出契约
- 陪议纪要：决策句 + 选项对比 + 反方压力测试 + 客户本人的决定与检视点。
- 预演报告：立场地图 + 模拟问答实录 + 改进建议。
- 问答预案库条目：核心回答 + 数据出处 + 禁说清单。
- 所有决策由客户本人做出并记录；教练意见不外传、不背书、不担保。
