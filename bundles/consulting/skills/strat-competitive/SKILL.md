# 竞争战略设计

## 适用场景
- 同质化竞争加剧，陷入价格战
- 新进入市场或新品类，需明确竞争姿态
- 战略模糊「什么都想要」，需做取舍

## 方法
1. 竞争格局测绘：用波特五力 + 战略群组图双工具定位，
   明确直接对手、潜在进入者与替代威胁；
   对手数据必须挂出处，不接受「听说」。
2. 客户价值要素拆解：通过客户访谈与购买数据拆解
   目标客户的购买决策要素排序（价格 / 品质 / 交付 / 服务 / 品牌），
   样本量与来源写明。
3. 三选一判断：成本领先 / 差异化 / 聚焦（成本聚焦或差异聚焦），
   用「能力禀赋 × 客户价值 × 对手空档」三角校验；
   警惕「夹在中间」，明确写出放弃的价值要素。
4. 配称体系设计：用活动系统图（Activity System Map）把战略选择
   翻译为研发 / 采购 / 生产 / 营销 / 服务的配套动作，
   校验各活动间「一致性 / 互相加强 / 投入最优化」三层配称。
5. 护城河诊断：对照规模经济 / 网络效应 / 转换成本 / 品牌 /
   特许资源五类护城河，评估所选战略的可防御性与加固动作。
6. 落地校验：输出「战略一句话 + 三个不做什么 + 五个配称动作」，
   用一线员工可理解的语言重写，做内部认知测试。

## 输出契约
- 竞争战略报告：格局测绘 + 客户价值要素排序（带访谈/数据回执）
  + 三选一结论与放弃清单。
- 活动系统配称图与护城河诊断表。
- 竞对信息只用公开渠道，涉密信息获取建议一律拒绝并提示合规风险（C-R7）。
- 战略取舍涉及业务与人员的收缩建议触发必审（C-R2）。
