# 薪酬体系设计

## 适用场景
- 薪酬内部不公平、外部无竞争力双重挤压
- 关键岗位离职率高，薪酬竞争力存疑
- 从拍脑袋定薪转向体系化管理

## 方法
1. 薪酬诊断：从「内部公平性 / 外部竞争力 / 激励性 / 成本可控性」
   四维度体检，用薪酬渗透率与离散度数据呈现问题，挂数据回执。
2. 岗位价值定锚：承接岗位价值评估结果（海氏/IPE）形成职级矩阵，
   作为内部公平的锚点。
3. 市场对标：选定对标市场（行业 × 地域 × 规模），
   采用 2 家以上第三方薪酬报告交叉验证，
   明确公司薪酬策略定位（领先 75 分位 / 跟随 50 分位 / 滞后），
   定位选择须与人才策略联动说明。
4. 结构与带宽设计：固定 : 浮动比例按岗位性质分层
   （销售类 6:4 / 职能类 8:2 等），每职级设
   最小值-中位值-最大值带宽，带宽重合度 30-50% 校验。
5. 套改测算：全员套改模拟，输出「低于带宽下限 / 高于上限 /
   正常落入」三类人群清单与处理策略（冻结 / 逐步归位 / 破格）；
   总成本增幅测算分三年摊销方案。
6. 调薪机制：年度调薪矩阵（绩效 × 薪酬渗透率）+
   晋升调薪规则 + 特殊调整审批流。

## 输出契约
- 薪酬体系方案：诊断报告 + 职级薪酬表 + 结构带宽设计 + 调薪矩阵。
- 对标数据注明报告来源、样本与年份（C-R7 提示数据时效）。
- 套改影响测算按人群分类汇总呈现；涉及个人薪酬明细
  按 C-R5 脱敏前置，仅授权 HR 与决策层可见。
- 套改结果与个别人薪酬调整交客户管理层逐人裁定（C-R2 必审），
  AI 不提供针对个人的降薪建议。
