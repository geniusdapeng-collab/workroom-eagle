# 异业合作设计

## 适用场景
- 品牌增长乏力，想通过异业合作低成本获客
- 有渠道或客流资源想变现，寻找互补合作方
- 已有合作意向但合作结构与利益分配谈不拢

## 方法
1. 互补性验证：客群重叠度 30-60% 为黄金区间——
   重叠过低合作无场景，过高则互为竞品；
   品牌调性、客单价带必须同档，高端品牌配低价品牌互相稀释。
2. 资源互换盘点：双方各出什么（流量、渠道、产品、内容、
   会员权益）列成互换清单并各自估值，
   「资源不对等」是合作破裂首因——先用货币口径把账算平。
3. 合作结构选型：联合营销（短期 campaign，按效果结算）、
   权益互通（会员权益互相嵌入，按核销量结算）、
   渠道互驻（店中店/联名专区，按分成或租金）、
   联名产品（共担成本共分毛利，知识产权归属前置约定）。
4. 联合营销算账：获客成本分摊（各自带来的新客归谁）、
   活动费用分摊比例、效果归因口径（券码/专属链接）事前约定，
   归因扯皮是联合营销复盘烂尾的重灾区。
5. 退出与风控条款：合作期限与试运营期（建议 3 个月试点）、
   数据共享边界（用户数据不可直接交换，只可各自触达——
   违反个人信息保护的红线提示，C-R7）、品牌风险连带条款。

## 输出契约
- 互补性评估：客群重叠度测算方法 + 调性匹配结论。
- 资源互换估值表：双方投入项与货币化估值，缺口与补齐方案。
- 合作结构建议：模式选型 + 结算口径 + 归因方案。
- 试点方案：3 个月试点目标、费用分摊、退出条件。
- 合作协议条款与数据合规由执业律师把关，本技能只出商业结构（C-R7）。
