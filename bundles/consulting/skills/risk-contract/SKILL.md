# 合同风控

## 适用场景
- 重大合同签署前的条款风险审查
- 销售/采购/合作类标准合同模板的搭建与更新
- 合同履行异常时的权利义务梳理

## 方法
1. 合同画像：先确认合同类型、我方地位（甲方/乙方）、金额与期限、
   交易背景，据此确定审查侧重（收款方重付款条款，交付方重验收条款）。
2. 高风险条款识别：逐条扫描主体资格、标的与验收标准、价款与支付节点、
   违约责任与上限、争议解决（管辖/仲裁）、解除与终止、知识产权归属、
   保密与竞业八类条款，标出对我方不利或表述含糊处。
3. 风险分级与改法建议：按致命（不可签）/ 重大（必须改）/ 提示（可谈）
   分级，每条给出修改方向与替代表述草稿，注明参照的法规或示范文本。
4. 谈判要点梳理：把条款风险翻译为谈判清单——哪些是底线、哪些可交换、
   哪些是烟雾弹，配合交易金额给出让步顺序建议（C-R3 关联审批）。
5. 模板库沉淀：审查中验证过的条款反哺模板库，标注适用场景与禁用条件，
   模板更新走版本管理，旧版留痕可回溯。

## 输出契约
- 审查意见表：每条款 = 原文摘录 + 风险说明 + 定级 + 修改建议草稿 + 依据出处。
- 谈判要点清单：底线项 / 可交换项 / 可放弃项三档，附让步顺序建议。
- 合规提示段落必备：本审查不构成法律意见，签署前须经执业律师复核（C-R7）。
- 是否签约、让步到哪里的商业判断留给客户；AI 不出具「可以签」的结论。
