# 客户培训体系

## 适用场景
- 方案交付期配套的能力转移培训
- 常年顾问服务中的客户团队系统化培养
- 客户内训师队伍从 0 到 1 搭建

## 方法
1. 能力盘点定靶：从方案落地所需动作反推能力项，对照客户团队现状
   评出差距等级（不会/会而不熟/能教人）；课程只为「差距且关键」的项开设。
2. 课程地图设计：按「理念（为什么）→ 方法（怎么做）→ 工具（用什么）」
   三层排课；每门课绑定一个真实业务场景与一份课后产出物，
   杜绝纯讲授式课程。
3. 课程开发：单课结构 = 案例导入（客户自己的案例优先）→
   方法讲解 → 现场演练 → 点评纠偏；演练素材全部取自客户真实业务，
   课件脱敏后归档。
4. 讲师培养：选拔业务骨干做内训师，按「观摩 → 共讲 → 独讲 →
   能带新人」四级进阶；每级设通关标准（现场评分 ≥ 4/5）；
   咨询师从主讲退为教练。
5. 效果评估四层：反应层（课后问卷）→ 学习层（前后测对比）→
   行为层（30/60 天动作抽查）→ 结果层（绑定业务指标变化）；
   至少做到行为层，只评反应层等于没评估。
6. 体系移交：结项时移交课程包（课件+讲师手册+题库+演练素材），
   约定 6 个月内一次回访复评。

## 输出契约
- 课程地图：能力项 × 差距等级 × 课程对照表，标注每课产出物。
- 讲师进阶台账：每位内训师的级别、通关记录与待提升项。
- 四层评估报告：各层数据与结论，行为层未达标课程的改进建议。
- 培训效果结论只作改进依据；个人学习评价交客户人力资源体系裁量。
