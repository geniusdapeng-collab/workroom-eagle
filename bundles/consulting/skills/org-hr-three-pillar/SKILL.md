# HR三支柱转型

## 适用场景
- HR 深陷事务性工作，无暇支持业务
- 集团化后 HR 管控模式重构
- 拟建共享服务中心降本增效

## 方法
1. 现状盘点：用 HR 工时结构分析（事务性 / 专业性 / 战略性占比）
   量化现状，访谈业务 leader 收集对 HR 的期待与痛点，
   输出转型必要性证据包。
2. 职责切分：按尤里奇三支柱模型切分——
   COE（政策与方案设计）/ HRBP（业务伙伴，诊断与落地）/
   SSC（事务集中与共享服务），
   用 RACI 表把 30-50 项 HR 工作逐一切分，消除三不管与重叠。
3. 服务目录与 SLA：SSC 输出服务目录（入职 / 异动 / 薪酬发放 /
   证明开具等），每项定 SLA 时限与满意度指标；
   明确哪些事项可自助化、系统化。
4. 能力重建：HRBP 能力模型（业务理解 / 诊断 / 影响 /
   数据素养）与选拔标准；现有 HR 转型路径
   「能转尽转、不能转安置」，涉及人员评价触发必审（C-R2）。
5. 分阶段落地：试点事业部 → 全公司推广两阶段，
   每阶段设「服务满意度 / 事务处理时效 / HRBP 业务评价」
   验收指标，未达标不推广。
6. 数字化承载：e-HR 系统与自助平台需求清单，
   员工数据权限按角色最小授权设计（C-R5）。

## 输出契约
- 转型方案：现状证据包 + 三支柱 RACI 切分表 + 服务目录与 SLA。
- HRBP 能力模型与试点-推广路线图（含验收指标）。
- 现有 HR 人员的转岗与安置建议触发必审（C-R2），
  涉及解除劳动关系部分转 org-layoff-compliance（C-R7）。
- 员工数据权限设计遵循最小授权与脱敏原则（C-R5）。
