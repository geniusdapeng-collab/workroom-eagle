# 关键人才保留

## 适用场景
- 核心骨干被竞对挖角或流露去意
- 变革期/并购期关键人流失风险升高
- 关键岗位继任者地图空档，需先保现有人

## 方法
1. 保留对象圈定：承接关键岗位清单与继任者地图，
   锁定「岗位关键 × 离职影响大 × 市场可替代性低」人群，
   名单属高敏信息，最小范围知悉（C-R2 必审）。
2. 离职风险信号扫描：建立信号清单——
   绩效突变 / 请假面试迹象 / 重要会议缺席 /
   期权临近成熟 / 直接上级变动 / 行业挖角活跃，
   信号只作关注依据，不作定性结论，避免自我实现预言。
3. 保留面谈：指导直线经理做结构化留任面谈（Stay Interview）——
   「什么让你留下 / 什么会让你离开 / 最近哪件事让你沮丧」，
   输出个人诉求画像（发展 / 认可 / 授权 / 回报 / 平衡）。
4. 一人一策组合：非现金激励工具箱优先——
   发展机会 / 授权扩大 / 项目曝光 / 导师配置 / 弹性安排，
   现金与股权类作为补充并测算成本；
   避免「会哭的孩子有奶吃」引发公平性崩塌。
5. 风险对冲：对挽留概率低的关键人，
   同步启动知识转移（文档化 / 影子计划）与继任者加速，
   保留方案与对冲方案并行。
6. 复盘机制：关键人流失案例逐例复盘，
   归因区分「薪酬 / 发展 / 管理 / 文化 / 个人」，
   复盘结论回灌制度修订。

## 输出契约
- 保留方案：对象名单（脱敏版 + 授权版分离）+ 风险信号清单
  + 留任面谈提纲 + 一人一策记录表。
- 涉及个人的评价与保留决策交客户管理层（C-R2 必审）；
  个人信息按 C-R5 脱敏前置。
- 涉及竞业限制、服务期协议等法律文件的安排提示律师审（C-R7）。
- 不做「监听式」员工监控建议，信号采集限于正常工作观察。
