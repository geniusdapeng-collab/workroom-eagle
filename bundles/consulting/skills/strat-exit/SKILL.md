# 退出策略规划

## 适用场景
- 创始人或投资人考虑退出路径与时点
- 拟 IPO 前 2-3 年的规范化准备
- 股东之间对退出安排存在分歧

## 方法
1. 退出诉求澄清：区分各股东的「时点诉求 / 价格诉求 / 控制权诉求」，
   诉求冲突先于方案设计前暴露并记录，避免后期翻烧饼。
2. 三路径比较：IPO / 并购出售 / 管理层回购（MBO）按
   「估值水平 / 时间周期 / 确定性 / 后续义务」四维度对照，
   输出比较矩阵与适配条件。
3. IPO 可行性扫描：对照目标板块上市标准做差距分析——
   财务指标 / 规范运作 / 独立性 / 同业竞争与关联交易，
   输出差距清单与 24-36 个月整改路线图；
   明确最终以上市规则与中介机构意见为准（C-R7）。
4. 并购退出准备：梳理卖方尽调资料包（数据室清单）、
   潜在买家画像与接触策略、竞业与留任安排。
5. MBO 可行性评估：管理层出资能力 / 融资结构 / 定价机制
   三要素评估，提示定价公允性与程序合规要求。
6. 估值预期管理：用可比交易与可比公司双口径给出估值参考区间，
   管理卖方预期；写明区间随市场波动，不构成承诺。
7. 退出准备清单：按「股权清晰 / 财务规范 / 法务干净 / 核心团队稳定」
   四类逐项核对，未达标项列入前置整改。

## 输出契约
- 退出路径比较矩阵 + 各路径适配条件与前置整改清单。
- 估值参考区间双口径，附「非正式评估、不构成承诺」声明（C-R7）。
- 股东诉求与退出安排属高敏议题，方案触发必审路由（C-R2），
  并建议股东另行咨询执业律师与税务师（C-R7）。
- 股东个人信息与持股明细按 C-R5 脱敏前置，最小可见授权。
