# 并购策略设计

## 适用场景
- 企业拟通过并购获取能力、市场或规模
- 已有潜在标的，需评估与谈判支持
- 并购完成后整合不力，需复盘与补救

## 方法
1. 并购逻辑澄清：明确并购要补的是「能力 / 客户 / 产能 / 牌照」
   中的哪一项，写进标的筛选标准第一条；
   逻辑不清的并购大概率失败，须先回战略层对齐。
2. 标的筛选：建筛选漏斗——战略匹配（否决项）→ 财务健康
   （收入 / 毛利 / 现金流门槛）→ 法律与合规红线 → 文化兼容性，
   每层设明确通过标准，输出长名单 → 短名单过程留痕。
3. 协同测算：分「收入协同 / 成本协同 / 财务协同」三类逐项测算，
   每项写明实现前提与达成年限；协同现值超过收购溢价的
   部分标红预警——溢价全靠协同兑现的交易风险极高。
4. 估值区间参考：提供可比公司法与 DCF 双口径的估值区间，
   标注关键假设；明确此为谈判参考而非正式评估报告，
   正式估值须由持牌评估机构出具（C-R7）。
5. 尽调清单：财务 / 法律 / 业务 / 人力四线并行，
   人力线重点核核心团队留任意愿与竞业安排；
   发现红线问题（重大诉讼 / 财务造假迹象）即建议终止。
6. 百日整合路线：按「保住客户 / 留住关键人 / 统一指挥」
   三优先设计整合百日计划，明确整合经理人选与决策授权。

## 输出契约
- 并购策略包：筛选漏斗 + 标的评分表 + 协同测算模型（带假设）。
- 估值区间双口径对照，附「非正式评估」声明（C-R7）。
- 尽调红线清单与整合百日计划模板。
- 交易拍板、对价与核心团队任免建议交客户决策层，触发必审（C-R2）；
  涉及标的公司员工个人信息按 C-R5 脱敏前置。
