# 企业文化落地

## 适用场景
- 价值观挂在墙上，行为没人践行
- 快速扩张稀释文化，老员工感慨「变味了」
- 并购整合期文化冲突

## 方法
1. 文化诊断：用 OCAI 组织文化评估或丹尼森模型施测，
   结合员工访谈提炼「实际运行的文化」与「宣称的文化」差距，
   访谈样本覆盖层级与司龄（C-R5 脱敏前置）。
2. 价值观行为化：每条价值观翻译为
   「3 条倡导行为 + 3 条反对行为」，
   行为描述必须具体到场景（如「客户投诉 24 小时内给初步答复」），
   用正反对照案例佐证。
3. 制度锚定审计：逐项审计招聘 / 晋升 / 考核 / 薪酬 / 奖惩制度
   与价值观的一致性，找出「制度鼓励的行为恰是价值观反对的」
   冲突点，输出制度修订清单——文化是制度的副产品。
4. 仪式与传播体系：设计入职 / 周年 / 表彰 / 复盘四类仪式，
   建文化案例库（真实故事，脱敏后传播），
   管理层「文化布道」列入日程而非口号。
5. 考核挂钩设计：价值观行为纳入考核的方式（如 360 行为项），
   写明挂钩比例与校准机制；
   涉及个人评价的用途触发必审（C-R2）。
6. 落地节奏：宣贯期（知）→ 试点期（行）→ 固化期（惯）
   三阶段各 3-6 个月，每期设行为观察指标。

## 输出契约
- 文化落地方案：诊断报告 + 价值观行为对照表 + 制度冲突清单。
- 仪式手册与案例库（案例脱敏，C-R5）。
- 价值观与考核挂钩方案涉及个人评价，触发必审（C-R2），
  挂钩比例交客户管理层裁定。
- 诊断中的负面访谈原话只以脱敏聚合形式呈现，不指向个人。
