# 财务报表分析

## 适用场景
- 老板看不懂报表，需翻译成经营语言
- 利润增长但现金紧张，需检验盈利质量
- 融资/贷款前需自查报表瑕疵
- 并购/投资前的标的财报初筛

## 方法
1. 口径核验：确认报表基础（权责发生制/收付实现制）、合并范围、
   会计政策变更与审计意见类型；所有分析数字必须挂报表页码或科目回执。
2. 三表联动勾稽：验证「净利润 + 折旧摊销 ± 营运资本变动 ≈ 经营现金流」、
   「资产负债变动 ≈ 现金流量表对应项」，勾稽断裂处即分析重点。
3. 盈利质量检验：计算「净现比 = 经营现金流净额 / 净利润」，
   连续两期 <0.8 亮黄灯、<0.5 亮红灯；拆解应收账款增速与营收增速差、
   存货周转恶化等利润注水信号。
4. 异常科目扫描：用同比变动率（>30%）与结构占比突变（>5pct）双规则扫描，
   重点盯其他应收款/预付款/在建工程/商誉等藏污科目；
   AI 批量比对附注明细与主表，标注解释不通的科目。
5. 经营语言翻译：把财务结论转译为「钱赚没赚到、钱收没收回来、
   家底厚不厚、还能撑多久」四问，每问给出数据支撑与行动建议。

## 输出契约
- 口径声明页：报表基础/合并范围/审计意见，数字全部挂回执。
- 三表勾稽验证表：断裂点清单 + 可能原因。
- 盈利质量评分：净现比趋势 + 注水信号清单（红/黄/绿）。
- 异常科目清单：触发规则/金额/疑点描述/待核实问题。
- 四问经营解读页；财务造假定性判断留给持证会计师与审计机构。
