# 库存优化

## 适用场景
- 库存高企占压现金流，仓库越建越大
- 呆滞料积压严重，账实不符
- 缺货与积压并存的结构性失衡

## 方法
1. 库存结构诊断：ABC（金额贡献）× XYZ（需求稳定性）
   九宫格分类全量物料，数据取近 12 个月出库记录挂回执；
   识别「AX 应少备 / CZ 应按单」的错配。
2. 分类策略矩阵：九类物料各定策略——
   AX/AY 安全库存 + 高频补货；AZ/BZ 谨慎备货 + 供应商协同；
   C 类简化管理（双箱法）；X 类按预测、Z 类按单。
3. 安全库存测算：按「需求波动 × 供应提前期波动 ×
   目标服务水平」公式测算，服务水平按物料重要度分档
   （95%/90%/85%），写明测算假设与参数来源；
   服务水平与缺货损失的取舍交客户决策。
4. 呆滞处置：定义呆滞标准（如 180 天无动态），
   按「折价销售 / 改制利用 / 供应商回购 / 报废」
   四路径处置，测算各路径损失与税务影响（提示税务师确认 C-R7）。
5. 库存健康指标：周转天数 / 呆滞占比 / 账实相符率 /
   齐套率四指标看板，目标值分阶段设定。
6. 长效机制：新品引入与退市流程的库存闸门、
   预测责任归属、月度库存复盘会议模板。

## 输出契约
- 库存优化方案：ABC-XYZ 分类全表 + 分类策略矩阵
  + 安全库存参数表（带假设）。
- 呆滞处置清单按路径分类，损失测算附税务提示（C-R7）。
- 库存健康指标看板与月度复盘模板。
- 报废处置涉及资产减值与税务处理，决策与金额交客户财务与管理层（C-R2 必审）。
