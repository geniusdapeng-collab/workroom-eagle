# 舆情预警

## 适用场景
- 客户品牌有 C 端曝光，需防范负面舆情发酵
- 新品上市/大促/公关活动期间的重点盯防
- 投诉集中爆发时的情绪走势追踪

## 方法
1. 监测面覆盖：微博、抖音、小红书、知乎、黑猫投诉、百度贴吧、
   应用商店评论、本地论坛；品牌词+产品词+高管名+常见变体/谐音词库。
2. 情感判定：对提及文本做正/负/中三分类，负面再分「投诉 / 质疑 / 谣言 / 玩梗」；
   讽刺与反话语境人工复核标记，避免误判。
3. 烈度分级：按传播量、账号权重（认证/粉丝量）、是否进热搜/同城榜，
   定 L1 关注 / L2 预警 / L3 危机三级；L2 起 30 分钟内推送。
4. 溯源定位：找首发源与关键放大节点，区分自然发酵与疑似有组织攻击
   （集中时段、文案雷同、新注册小号比例），为处置提供依据。
5. 趋势外推：按 2 小时粒度画声量曲线，标注拐点；对比历史同类事件
   走势给出「发酵中/见顶/回落」判断，判断依据透明列出。
6. 处置参考：附同类案例处置效果复盘，仅作参考；对外口径与回应文本
   必须由客户决策（必审 C-R2），AI 不代发任何公开回应。

## 输出契约
- 预警单：分级+首发源+传播节点+声量曲线+趋势判断，30 分钟内送达。
- 日报：声量总览、负面占比、Top 负面话题及处置进展跟踪。
- 危机处置建议仅列选项与案例，回应口径必审（C-R2）。
- 涉及个人信息的舆情内容做脱敏前置处理（C-R5），不扩散当事人隐私。
