# 合伙机制设计

## 适用场景
- 新合伙关系建立时的规则设计（创业合伙、门店合伙、项目合伙）
- 合伙矛盾初显时的规则补救与协议补签
- 合伙扩张（吸收新合伙人）时的机制升级

## 方法
1. 合伙模式确认：先厘清是普通合伙、有限合伙还是公司制股权合伙，
   不同模式下责任承担、税负、治理规则差异逐项说明，不替客户选型。
2. 进入规则设计：出资形式与估值口径（现金/实物/劳务/资源的折算）、
   分期到位安排、新合伙人进入的决策门槛与定价机制，逐项列要点。
3. 议事规则设计：日常经营决策权归属、重大事项清单（对外担保、
   大额支出、利润分配、新合伙人进入）及表决比例、僵局打破机制
   （轮值/第三方调解/一票否决的慎用边界）。
4. 退出与散伙条款：退出情形分类（正常退出/除名/死亡/失联）、
   财产清算与份额作价方法、竞业与保密义务、散伙时的资产与客户
   分割原则，每类给出条款要点而非现成文本。
5. 矛盾场景压测：用「出工不出力」「账目不信任」「私接业务」
   「离婚/债务牵连合伙财产」四个高发场景压测规则完备性。

## 输出契约
- 合伙机制要点清单：进入/议事/退出/散伙四部分的条款要点与决策选项。
- 场景压测报告：四场景下的规则漏洞与补救建议。
- 重大事项清单建议稿：事项 + 表决比例建议 + 依据。
- 合规提示必备：协议文本须经执业律师起草并复核后签署（C-R7）；
  规则取舍由合伙人协商决定，AI 只呈现各选项的后果。
