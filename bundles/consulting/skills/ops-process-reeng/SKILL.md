# 流程再造优化

## 适用场景
- 流程环节多、审批长，客户抱怨响应慢
- 部门墙导致流程断点，反复返工
- 数字化上线前需先梳理优化流程

## 方法
1. 流程选择：用「客户影响 × 问题严重度 × 改造收益」
   三维度选出 1-3 条核心流程，拒绝全面开花。
2. AS-IS 测绘：跨部门流程穿越（Process Walk）实录每个环节——
   活动 / 责任人 / 系统 / 表单 / 耗时 / 等待时间，
   输出泳道图（SIPOC + Swimlane），数据现场采集挂回执。
3. 断点与浪费诊断：按 ECRS（取消 / 合并 / 重排 / 简化）
   逐项审视；识别七类典型问题——重复录入 / 无效审批 /
   等待 / 返工 / 多头接口 / 职责真空 / 信息断点。
4. TO-BE 设计：新流程泳道图 + 环节说明，
   明确每个环节的输入输出标准与责任人；
   设计校验指标：环节数压缩率 / 周期压缩率 / 审批层级 ≤ 3。
5. 系统与制度配套：流程变化涉及的系统改造点、
   授权调整与制度修订清单逐项列出，防止流程图与实际脱节。
6. 切换方案：试点运行 → 并行期 → 全面切换三阶段，
   每阶段设验收指标与回退预案；
   涉及岗位调整的配套方案触发必审（C-R2）。

## 输出契约
- 流程优化包：AS-IS/TO-BE 泳道图对照 + 问题清单（带现场数据）
  + ECRS 改进表。
- 系统改造与制度修订清单，责任到部门。
- 效率承诺只写测算区间与依据，不写「保证提升 X%」。
- 流程变革涉及岗位撤销或人员安置的转 org-layoff-compliance（C-R7），
  涉及个人职责变化的评价交客户管理层（C-R2 必审）。
