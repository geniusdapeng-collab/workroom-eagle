# 股权架构设计

## 适用场景
- 创始团队搭建时的股权分配与进入机制设计
- 融资前的股权结构梳理与代持清理
- 核心员工股权激励池的设立与调整

## 方法
1. 现状盘点：梳理现有股权结构——直接持股、代持、期权承诺、
   历史变动，标注出资到位情况与口头承诺未落地项，
   形成股权现状图与风险清单。
2. 分配逻辑梳理：按资金、全职投入、技术/资源入股、历史贡献四类
   贡献拆解各合伙人的入股依据，识别「拍脑袋均分」「人情股」
   等隐患结构并提示后果场景。
3. 控制权安排要点：梳理表决权比例关键线（67%/51%/34%/10%）、
   一致行动协议、AB 股、董事会席位安排等工具的使用条件与代价，
   列出各方案的控制力与融资兼容性对照。
4. 动态调整机制：设计股权成熟机制（分期兑现、离职回购价格公式）、
   增发与稀释规则、股权池预留比例的要点清单，
   明确触发条件与计算口径。
5. 风险场景推演：推演合伙人中途退出、离婚析产、身故继承、
   融资稀释四种场景下结构的稳健性，暴露的漏洞单独列清单。

## 输出契约
- 股权现状图与风险清单：含代持、未兑现承诺等隐患标注。
- 架构要点方案：分配逻辑 + 控制权工具对照表 + 动态调整机制要点。
- 场景推演报告：四种风险场景下的结构漏洞清单。
- 合规提示必备：本内容不构成法律/税务意见，股权协议须经执业律师
  起草复核、涉税安排经税务师复核后签署（C-R7）；最终分配由合伙人协商决定。
