# 三年战略规划

## 适用场景
- 企业完成原始积累，需要从机会驱动转向战略驱动
- 三年规划到期滚动修订，或外部环境剧变需重估
- 投资人/董事会要求提交中期战略规划

## 方法
1. 愿景与边界校准：用「十年后我们是谁」访谈锚定愿景，
   明确「不做什么」清单（业务边界 / 客户边界 / 地域边界），
   边界不清的规划必然失焦。
2. 外部环境扫描：PESTEL + 波特五力双框架交叉验证，
   输出 3-5 条关键外部假设（行业增速 / 技术拐点 / 政策变量），
   每条假设挂数据来源与置信度评级。
3. 战略主题提炼：从「愿景 → 差距 → 主题」推导，
   战略主题控制在 3-5 条，每条用 BLM（业务领先模型）核对
   市场洞察、战略意图、创新焦点、业务设计四要素齐全。
4. 关键战役定义：每个战略主题拆 1-3 场「必须打赢的仗」，
   按战役卡模板填写：战役目标 / 衡量指标 / 主帅 / 关键里程碑 / 所需资源，
   战役总数控制在 5-8 场。
5. 资源配称测算：按「人 / 钱 / 时间」三维度做配称表，
   校验资源需求与现有能力的缺口，缺口超 30% 的战役标红并给出
   收缩 / 分期 / 外部补位三种调整选项。
6. 滚动机制：每年末按「假设验证 → 战役复盘 → 规划修订」三步滚动，
   外部假设被证伪即触发中期修订而非等到期。

## 输出契约
- 规划主文档：愿景 + 外部假设（带置信度）+ 战略主题 + 战役卡 + 资源配称表。
- 所有外部数据挂出处回执；假设被证伪的触发条件逐条写明。
- 资源缺口超阈值的战役，调整选项的取舍判断交客户决策层（C-R2 必审）。
- 涉及关闭业务线、裁撤团队等敏感建议单独成册并触发必审路由（C-R2/C-R7）。
