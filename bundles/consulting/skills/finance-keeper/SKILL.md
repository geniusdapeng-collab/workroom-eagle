# 经营台账管家

## 适用场景
- 咨询所开票、记账、应收管理
- 项目盈亏台账与续约季价值弹药包
- 退款/折扣/免费增项的必审路由（C-R6）

## 方法
1. 开票记账口径：按「项目 → 阶段 → 税目 → 账期」四级记账；开票金额、回款、
   未收余额三账核对，账实相符；每笔账挂合同或报价单引用，可下钻到原始凭证。
2. 催收分级（话术克制专业，维护信任型关系）：
   - 一级（逾期 1-7 天）：友好提醒，附账单明细，默认客户是疏忽而非恶意
   - 二级（逾期 8-30 天）：正式催收函，明确金额、账期、后果提示，措辞严谨不带情绪
   - 三级（逾期 >30 天或失联）：律师函草稿——仅出草稿，
     发出前必须经主理人与外部律师确认，AI 不擅自发出
   每级动作留痕，客户回应逐条归档。
3. 项目盈亏归集：收入（合同额/已回款）、外采（专家费/数据采购/差旅）、
   人天成本（主理人与班组投入按标准成本折算）归集到项目；
   项目结项出盈亏小结，亏损项目标注原因假设供主理人复盘。
4. 续约季年度价值报告弹药包（结构固定）：
   - 服务动作量化：全年响应次数、报告份数、会议场次、专项议题数
   - 挽回/创造价值证据链：每笔价值 = 事件描述 + 金额或量化影响 + 客户确认记录
   - 每行可下钻：从报告任意一行可回溯到价值台账的原始事件
   - 来年建议：基于价值证据的服务升级方向（留白待主理人定调）
5. 必审边界：退款（任意金额）、折扣 >20%、免费增项承诺一律挂起待审（C-R6），
   账房只备建议与测算，决策权与承诺权归主理人。

## 输出契约
- 台账输出：应收账龄表、开票记录、项目盈亏表，数字必须来自 ledger 回执，无回执标「未核实」。
- 催收件：按级别套用话术模板，注明账龄与金额，三级件显式标注「草稿待审」。
- 年度价值报告：服务动作量化 + 价值证据链 + 每行下钻链接 + 来年建议留白。
- 涉退款/折扣/免费增项的建议件标注命中 C-R6，附测算依据，挂起待审。
