# 价值链诊断

## 适用场景
- 客户毛利下滑但说不清钱亏在哪个环节
- 研产供销服各环节各自为政，需全链路视角
- 外包/自制/砍环节的取舍决策支持

## 方法
1. 链路建模：按客户实际业务画价值链主流程（研发-采购-生产-
   营销-销售-交付-服务），标注每个环节的责任部门与核心产出。
2. 成本归集：用作业成本法（ABC）思路把期间费用分摊到各环节，
   数据取自财务科目+ERP 工单；分摊规则透明列出，争议口径单列。
3. 增值性分级：每环节判定「直接增值 / 必要不增值 / 浪费」——
   检验标准是「客户是否愿意为这个环节付钱」，浪费环节量化其成本额。
4. 瓶颈定位：用约束理论（TOC）找制约整体产出的瓶颈环节，
   指标=环节周期占全链路比+等待队列长度+瓶颈利用率是否 >90%。
5. 对标量化：瓶颈环节与行业标杆对比（单位成本、周期、一次通过率），
   标杆数据标注来源（行业报告/上市公司披露/专家估计）。
6. 优化输出：环节级诊断表+瓶颈改进方案+外包/自制测算；
   涉及裁撤环节与人员的建议必审（C-R2）。

## 输出契约
- 价值链诊断表：环节-成本-周期-增值分级-瓶颈标注，数据可溯。
- 瓶颈分析：瓶颈证据链+放开瓶颈的收益测算逻辑。
- 优化方案：每方案带投入、预期收益、风险三栏。
- 组织与人员调整类建议必审（C-R2），注明需配套变革管理。
