# 线索分诊

## 适用场景
- 新线索入站后的登记、查重、资格初筛与分级
- 跟进节奏管理与超期告警
- 冷线索池的每周复核（低分不丢弃，防误判）
- 初步报价响应（仅限标准价目且金额达标线内，C-R1）

## 方法
1. 五元化登记：每条线索记录「来源渠道 / 联系人及角色 / 需求自述 / 预算信号 / 期望时效」五要素，
   先查重再建卡，同一企业的多次接触归并到同一条线索主线，避免档案重复。
2. 资格四维评分（各 1-5 分）：
   - 预算：有无明确预算区间、付费能力信号（企业规模、历史采购）
   - 决策人：对接人是否决策链上的人，距最终决策人几层
   - 需求真实性：需求是否具体、有场景、有痛点细节，还是泛泛「想了解了解」
   - 匹配度：是否在主理人服务行业与能力半径内，是否理想客户画像
   加权得总分，分三级：A（本周必跟）/ B（常规跟进）/ C（入冷线索池）。
3. 跟进节奏：A 级 24 小时内首次响应、3 天内约澄清会；B 级 3 天内响应、每周一跟；
   任何级别超期未动作即升级提醒主理人，跟进动作逐条留痕。
4. 冷线索池机制：C 级不删除、不标记为「无效」，只降频。每周一生成「5 分钟速览清单」
   （每条一行：企业、需求一句话、入池原因、触发动议的信号），由主理人快速复核；
   出现预算到位、决策人变更、行业热点等信号时立即复活升级。
5. 初步报价边界：仅限标准价目表内项目且金额达标线内可自动草拟响应（C-R1）；
   越线或需求模糊需定制方案的，转方案架构师，线索侧不报价。

## 输出契约
- 每条线索输出：五元化登记卡 + 四维评分表 + 分级结论 + 建议动作与截止时间，写入 decision.basis。
- 周输出：冷线索池速览清单（每条一行），标注本周信号变化。
- 资格评分所依据的信息标注来源（客户自述/公开检索回执）；无回执标「未核实」。
- 报价类动作注明是否命中 C-R1 自动线，越线件标注「已转方案架构师并挂起」。
