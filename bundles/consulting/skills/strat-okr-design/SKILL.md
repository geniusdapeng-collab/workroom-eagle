# OKR体系设计

## 适用场景
- 企业从 KPI 转向 OKR，或 OKR 流于形式需重建
- 公司目标与部门动作「两张皮」，需对齐机制
- 快速扩张期需要透明的目标协同体系

## 方法
1. 适用性诊断：先判断业务是否适合 OKR——
   目标不确定性高、依赖跨部门协同、知识型工作占比高的业务适配；
   强执行型标准化业务建议保留 KPI，避免一刀切。
2. 公司级 OKR 起草：从年度经营计划承接 3-5 个 O，
   每个 O 配 2-4 个 KR；用 KR 质量清单校验——
   可衡量 / 有挑战（50-70% 把握）/ 结果导向（非动作）/ 有时限。
3. 三级对齐规则：部门 O 必须支撑至少一个公司 KR，
   个人 O 同理；绘制对齐地图（Alignment Map）可视化检查，
   出现「无人承接的公司 KR」或「无源的个人 O」即打回。
4. 评分机制：采用 0-1.0 制，0.6-0.7 为健康区间；
   明确 OKR 评分与绩效薪酬「弱挂钩」规则，
   强挂钩会导致不敢设挑战性目标，须在方案中写明理由。
5. 节奏设计：季度设定 → 双周 Check-in（进展/障碍/调整）→
   季末评分与复盘（事实 / 归因 / 下一步），
   提供 Check-in 与复盘会议模板。
6. 系统承载：建议用简表或 OKR 工具承载，全员可见；
   涉及个人 OKR 数据按最小可见原则授权（C-R5 脱敏前置）。

## 输出契约
- OKR 制度文件：对齐规则 + KR 质量清单 + 评分规则 + 会议模板。
- 首季公司级与部门级 OKR 样例，每个 KR 标注校验结论。
- OKR 与绩效薪酬的挂钩方案涉及个人利益，交客户管理层裁决（C-R2 必审）。
- 个人 OKR 数据含 PII，对外展示与归档前脱敏（C-R5）。
