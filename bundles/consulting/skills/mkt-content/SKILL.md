# 内容营销体系

## 适用场景
- 内容产出靠灵感，无选题库与生产流程
- 有内容无转化，内容与业务目标脱节
- 爆款靠运气，缺少可复制的爆款方法论
- 多平台内容分发，缺乏统一策略与归因

## 方法
1. 选题库搭建：三条来源并行——
   - 用户需求：AI 批量分析搜索下拉词、知乎/评论区高频问题（样本≥300 条），聚类成需求主题；
   - 竞品爆款：抓取竞品高互动内容 TOP50，拆解选题角度与情绪点；
   - 业务关键词：产品卖点/客户成功案例反向翻译成用户语言。
   选题库按「流量型/信任型/转化型」三分类管理，比例建议 5:3:2。
2. 爆款拆解框架：每条爆款按「标题钩子/开头 3 秒/结构（观点-论据-行动）/
   情绪曲线/互动引导」五要素拆解，沉淀为可复用模板，AI 承担批量拆解，人负责审美判断。
3. 内容生产线：选题会（周）→ 大纲（AI 初稿）→ 人工精修 → 排版分发 → 数据回收，
   每环节注明负责人与 SLA；AI 初稿必须人工过审，事实性内容核对来源。
4. 内容-转化归因：UTM 参数 + 内容 ID 埋点，计算「内容转化率 = 线索数 / 阅读数」，
   多触点归因采用首次触达 + 末次触达双口径呈现，避免单口径误导。
5. 内容质检：涉医疗、金融、教育等敏感表述自动拦截；
   所有对外发布内容必审（C-R2），AI 生成内容须标注并人工签发。

## 输出契约
- 选题库表：选题/分类/需求来源/优先级，量≥50 条起步。
- 爆款拆解模板：五要素拆解 + 可复用句式清单（注明拆解样本量）。
- 生产线 SOP：环节/负责人/SLA/质检点，AI 介入点明确标注。
- 归因报表：分内容 ID 的阅读量/线索数/转化率，双口径归因并列。
- 对外发布内容必审（C-R2）；选题方向与品牌调性的取舍留客户判断。
