# 大模型选型

## 适用场景
- 企业要在多家大模型（含国产模型池）间做选择与组合
- 模型成本随用量失控，需要路由与降本策略
- 行业有数据不出域要求，需要私有化/国产化部署评估
- 模型快速迭代，需要建立持续评测与切换机制

## 方法
1. 利益中立声明：本技能不与任何模型厂商存在佣金、返点或
   股权关联；如有既往合作须披露，评测数据全部留档可复核。
2. 场景分层：把企业 AI 场景按能力要求分层——复杂推理
   （方案/分析）、常规生成（文案/摘要）、结构化提取、
   嵌入检索；不同层用不同档位模型，避免「全场景上旗舰」。
3. 三维评测：
   - 场景能力：用企业真实任务构建评测集（脱敏处理，C-R9），
     跑各候选模型，按准确率/合格率打分，不看厂商跑分；
   - 成本：按预估 token 量测算月费，含输入输出价差与
     缓存策略空间；
   - 合规：数据出境、行业监管、私有化部署可行性（C-R9）。
4. 国产模型池评估：对主流国产模型按上述三维同标准评测；
   涉密/强监管场景优先评估可私有化部署的开源或国产商用模型。
5. 路由策略：设计「简单任务走小模型、复杂任务走大模型、
   失败自动升级」的路由层；多模型冗余避免单点依赖与
   厂商锁定，切换成本前置评估。
6. 持续评测：每季度用更新后的评测集复测，模型版本升级
   须回归测试，防止「静默升级」导致线上效果漂移。

## 输出契约
- 评测报告：各模型在真实评测集上的得分 + 成本测算 + 合规结论。
- 选型建议：分场景模型组合 + 路由规则（附利益中立声明）。
- 切换与冗余方案：锁定风险评估与迁移成本。
- 涉数据出境与行业监管的合规判断须法务确认（C-R9）；
  最终签约与预算由企业决策，AI 只给选项与证据。
