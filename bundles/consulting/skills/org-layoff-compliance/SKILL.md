# 人员优化合规方案

## 适用场景
- 业务收缩、组织合并涉及人员裁减
- 经济性裁员或结构调整的合规路径设计
- 个别人员协商解除的方案支持

## 方法
1. 路径比选：按劳动合同法框架比较
   协商解除 / 经济性裁员 / 客观情况重大变化解除等路径的
   「适用条件 / 程序要求 / 补偿标准 / 风险等级」，
   优先协商解除；明确 AI 输出仅为路径信息整理，
   不构成法律意见，方案必须经执业律师审核（C-R7）。
2. 范围与标准：优化范围由业务必要性推导，
   选用标准必须客观（岗位撤销 / 绩效记录 / 技能匹配），
   严禁以年龄、性别、婚育、健康等受保护特征为标准——
   出现即否决并提示违法风险。
3. 补偿测算：按法定 N / N+1 基准逐人测算，
   列明代通知金、未休年假折算、社保衔接等明细，
   输出汇总预算与单人测算表（单人表属 PII，C-R5 脱敏前置）。
4. 程序合规清单：经济性裁员的「说明情况 / 听取意见 /
   报告劳动部门」程序节点逐项列明，程序瑕疵是败诉主因。
5. 沟通方案：沟通话术模板（事实陈述 / 补偿说明 / 过渡支持），
   禁止话术中出现歧视性、威胁性表述；
   安排一对一沟通的顺序、人员与应急预案。
6. 风险预案：劳动仲裁风险分级、舆情风险预案、
   留任团队安抚方案（幸存者综合征）。

## 输出契约
- 方案包：路径比较表 + 程序合规清单 + 补偿测算（汇总页 +
  单人表分离）+ 沟通话术 + 风险预案。
- 全文强制附 C-R7 合规提示段落：本方案不构成法律意见，
  执行前必须经执业律师审核；当地法规与裁判口径以律师意见为准。
- 本技能全部输出触发必审路由（C-R2/C-R7），未经人工审核不得交付客户执行。
- 员工个人信息全程脱敏（C-R5），单人测算表仅授权 HR 与律师可见。
