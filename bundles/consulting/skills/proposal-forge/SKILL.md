# 提案锻造

## 适用场景
- 咨询项目提案初稿生成与报价测算
- 报价分级处置：小额标准价自动（C-R1）/ 大额与非标必审（C-R3）
- 价值定位与差异化卖点由主理人定调，AI 留白

## 方法
1. 客户理解复述：提案开篇先复述客户处境与需求（来自档案与澄清会纪要），
   让客户感到「被听懂」；复述不准确是提案第一大死因，此段必须逐句对照档案。
2. 五段结构展开：
   - 理解：客户处境、需求、未被言明的期待
   - 诊断：前期发现摘要（挂诊断素材包引用，不展开全文）
   - 方案：解决框架、工作模块、交付物清单
   - 路径：阶段划分、里程碑、双方投入与配合要求
   - 报价：报价表 + 测算说明 + 付款条款
3. 七成原则：模板 + 客户档案可生成约 70% 内容（理解复述、诊断摘要、方案框架、路径排期）；
   价值定位、差异化卖点、对关键决策人的针对性表达留白，标注「待主理人定调」。
4. 报价测算：工作量拆解到模块与人天，× 标准价目表得出基准价；
   测算明细可下钻（每个数字对应人天与价目行），折扣空间不主动让出，留主理人谈判。
5. 分级送审：金额 ≤2 万元且全部走标准价目 → 可自动响应（C-R1）；
   金额 >10 万元或含非标付款条款 → 挂起必审（C-R3）；
   两者之间按 default_level 走 review。外发前附测算明细与风险点提示。

## 输出契约
- 提案初稿：五段结构，「待主理人定调」留白处显式标注，全文挂档案引用链。
- 报价测算表：模块/人天/单价/小计四列，价目来源来自 quote.calc 回执，无回执标「未核实」。
- 送审包：初稿 + 测算明细 + 风险点提示 + 命中围栏标注（C-R1 自动 / C-R3 必审）。
- 不承诺档案能力范围之外的交付与效果；效果表述用「目标」而非「保证」。
