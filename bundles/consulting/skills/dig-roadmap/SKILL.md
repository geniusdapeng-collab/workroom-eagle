# 数字化转型路线图

## 适用场景
- 企业系统零散、数据割裂，需要一张统一的数字化蓝图
- 老板想转型但不知从何下手，需要分阶段路径与优先级
- 集团对子公司下达数字化任务，需要可汇报的规划方案
- 年度 IT 预算编制前，需要项目组合与投资节奏建议

## 方法
1. 现状盘点：梳理现有系统清单（ERP/MES/CRM/OA 等）、数据流转断点、
   纸质与 Excel 流程占比、IT 团队能力；输出「数字化成熟度雷达图」，
   按研产供销服财六个域分别打分，打分须有访谈与系统截图佐证。
2. 目标对齐：从公司战略反推数字化目标（降本/增收/管控/体验），
   与一把手确认未来三年最想解决的三件事，避免「为数字化而数字化」。
3. 路径设计：按「夯基（数据与流程标准化）→ 贯通（系统集成与主数据）
   → 智能（BI 与 AI 应用）」三段编排，每段 12-18 个月，
   标明依赖关系与前置条件，不许跳过夯基直接画智能大饼。
4. 速赢筛选：从痛点清单中筛 2-3 个 90 天内可见效的项目
   （如审批线上化、报表自动化），标准是投入小、周期短、有 owner，
   用于建立组织对转型的信心。
5. 投资与配套：测算三年总投资区间（软件/实施/人力），
   明确 IT 编制缺口与外部依赖，给出「自研/外采/混合」建议。

## 输出契约
- 数字化蓝图：成熟度雷达 + 三段路径图 + 项目组合甘特（含依赖关系）。
- 速赢清单：2-3 个项目各附痛点、预期收益、90 天里程碑与负责人。
- 投资测算：分年度投资区间与人力缺口，数字必须标注假设与口径。
- 目标取舍与节奏决策（如先上 ERP 还是先上 BI）须由管理层确认，
  AI 只提供选项与利弊，不替企业拍板。
