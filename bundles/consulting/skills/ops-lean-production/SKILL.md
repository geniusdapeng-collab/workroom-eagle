# 精益生产导入

## 适用场景
- 制造企业成本高、交付慢、库存大
- 现场管理粗放，在制品堆积
- 学过精益但工具落地不了

## 方法
1. 标杆线选择：选「问题典型 × 团队配合度高 × 周期可控」的
   一条产线或一个产品族作为突破口，拒绝全面铺开。
2. 价值流图（VSM）现状测绘：从客户需求反推，
   实录每工序的周期时间（CT）/ 换型时间（C/O）/ 良率 /
   在制品库存 / 信息流向，计算增值比（增值时间/总周期），
   数据现场秒表实测 + MES 核对双源验证。
3. 七大浪费识别：过量生产 / 等待 / 搬运 / 过度加工 /
   库存 / 动作 / 不良品逐项对标现状图，量化浪费金额。
4. 未来状态图设计：确定节拍时间（Takt）→ 连续流可达性判断 →
   无法连续处设超市拉动（Kanban）→ 定拍工序与排产方式，
   输出未来 VSM 与差距清单。
5. 改善周实施：5 天 Kaizen Event 标准日程——
   周一培训与现状 / 周二周三方案与试做 / 周四验证 /
   周五标准化与发表；每个改善点写清「前后对比数据」。
6. 固化与推广：标准作业组合票（SOS/JES）+ 目视化管理 +
   班前会点检机制，30/60/90 天跟进表防回潮。

## 输出契约
- 精益诊断与改善包：现状 VSM + 七大浪费量化表 + 未来 VSM
  + 改善周成果对照（前后数据挂回执）。
- 标准作业文件与目视化方案模板。
- 改善收益按「已验证 / 待验证」分栏呈现，不虚报。
- 精益涉及人员精简的敏感结论单独标注并触发必审（C-R2/C-R7），
  优先建议转岗安置而非裁减。
