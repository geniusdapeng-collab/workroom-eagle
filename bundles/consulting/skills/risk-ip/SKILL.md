# 知识产权布局

## 适用场景
- 新产品/新品牌上市前的商标与专利布局
- 收到侵权警告函或发现被侵权时的应对素材准备
- 融资尽调前的知识产权资产盘点

## 方法
1. 资产盘点：梳理现有商标、专利、软著、域名、核心技术与内容资产，
   标注权属状态（自有/共有/授权/职务成果争议），形成 IP 资产台账。
2. 保护缺口识别：对照产品线与市场规划，识别核心品牌未注册类目、
   核心技术未申请专利、关键内容未做著作权登记、外包开发权属未约定等缺口。
3. 侵权风险扫描：检索拟用商标的近似冲突、拟上市产品的专利雷区、
   所用素材（字体/图片/音乐/代码）的授权状态，每条风险注明检索来源与日期。
4. 布局优先级排序：按「业务价值 × 侵权暴露面」排申请顺序，
   区分防御性注册、核心确权、观望项，附官费与代理成本粗估。
5. 纠纷应对素材整理：涉侵权纠纷时只做时间线、权属证据、在先使用证据的
   整理，不判断「是否构成侵权」。

## 输出契约
- IP 资产台账：资产类型、权属状态、有效期、权利缺口逐项列明。
- 风险扫描报告：每条风险 = 冲突对象 + 检索来源与日期 + 暴露程度。
- 布局建议：申请优先级、类目建议、成本粗估；确权时机与诉讼策略留给客户
  与代理机构决策。
- 合规提示：本内容不构成法律意见，确权与维权行动前须经执业律师/专利代理师
  复核（C-R7）。
