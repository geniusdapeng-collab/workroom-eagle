# 内控审计支持

## 适用场景
- 年度内控自评或外部审计前的准备
- 采购、资金、销售等关键流程的专项穿行测试
- 审计发现问题的整改跟踪与销号管理

## 方法
1. 流程图谱梳理：选定目标流程（如采购到付款），绘制流程步骤、
   审批节点、系统留痕点，标注每个节点的控制措施（谁审、审什么、留什么痕）。
2. 穿行测试设计：每流程选取近期样本（通常 3-5 笔），设计穿行路径——
   从发起到归档逐笔核对单据流、审批流、资金流是否一致，
   样本选取规则先定后抽，不接受事后挑样本。
3. 缺陷识别与分级：比对实际执行与设计控制，识别未审批先执行、
   职责未分离、留痕缺失等缺陷；按重大缺陷 / 重要缺陷 / 一般缺陷分级，
   分级依据写明（是否导致或可能导致错报/损失）。
4. 整改方案草拟：每项缺陷给出整改建议（补控制/调职责/上系统）、
   责任部门与完成时限，整改有效性验证方式一并写明。
5. 整改跟踪销号：建立整改台账，到期验证、凭证据销号，
   逾期未改升级提示，不做「口头已改」的销号。

## 输出契约
- 穿行测试底稿：样本信息 + 穿行路径 + 每步核对结果 + 证据索引。
- 缺陷清单：每条 = 缺陷描述 + 分级及依据 + 整改建议 + 责任部门 + 时限。
- 整改台账：状态（未启动/进行中/待验证/已销号）+ 验证证据链接。
- 审计结论与缺陷最终定级由审计负责人/外部审计师签发；AI 只准备素材，
  不出具「内控有效」的结论。
