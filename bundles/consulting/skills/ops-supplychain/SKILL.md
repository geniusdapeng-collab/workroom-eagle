# 供应链优化

## 适用场景
- 缺货与积压并存，计划失灵
- 部门各自为政，销售抱怨交付、财务抱怨库存
- 供应链成本占比高，需系统优化

## 方法
1. SCOR 框架诊断：按计划（Plan）/ 采购（Source）/
   生产（Make）/ 交付（Deliver）/ 退货（Return）五环
   对标行业标杆，输出各环节 KPI 基线
   （订单满足率 / 交付周期 / 库存周转 / 现金周期），挂数据回执。
2. 需求与计划优化：区分预测驱动与订单驱动产品
   （按需求可预测性 × 供应柔性矩阵），
   建立「统计预测 + 销售修正 + 计划终审」三级预测流程，
   用 MAPE 度量预测准确度。
3. S&OP 机制设计：月度 S&OP 五步——数据准备 / 需求评审 /
   供应评审 / 预备会 / 高管决策会，
   输出会议模板与供需平衡决策清单，
   明确冲突升级与裁决规则。
4. 采购与供应商协同：供应商分级（战略 / 优选 / 一般）+
   分级协同策略（VMI / JIT / 框架协议），
   关键物料双源策略与断供风险评估。
5. 物流网络优化：仓网布局（CDC/RDC 层级）、
   运输方式组合、配送半径测算，
   用「总成本 = 仓储 + 运输 + 库存持有 + 缺货损失」
   全成本模型比选方案。
6. 指标体系：建立供应链记分卡，KPI 间制衡关系写明
   （如库存周转与订单满足率的取舍由高管定）。

## 输出契约
- 供应链优化方案：SCOR 对标报告 + 预测流程 + S&OP 机制文件
  + 供应商分级策略。
- 全成本模型的参数与假设逐条列明，数据挂回执。
- KPI 取舍建议写明利弊，取舍决策交客户高管（C-R2 必审）。
- 涉及供应商汰换与采购人员职责调整的敏感内容触发必审（C-R2）。
