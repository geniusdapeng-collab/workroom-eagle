# 客户成功体系

## 适用场景
- 常年顾问新合约启动（onboarding）的标准化承接
- 服务中期的采用度与成果管理
- 多客户并行时的 CS 流程与节拍治理

## 方法
1. Onboarding 三十天：D1 启动会（对齐目标/对接人/数据权限）、
   D7 完成档案初始化（历史交付物、口径表、关键人图谱）、
   D15 交付第一份基线诊断（客户当前在哪）、
   D30 共同确认年度成功计划（目标/节拍/验收标准）——
   成功计划由客户签字，是全年的对赌锚点。
2. 服务节拍表：日（值守与响应记录）/ 周（轻触点：一条观察或一个提醒）/
   月（月度观察报告+月度会）/ 季（季度经营复盘+健康度评估）/
   年（年度价值报告+续约议程）；节拍写入日历，断档自动预警。
3. 采用度管理：跟踪客户对服务产出的实际使用——
   报告是否被读、建议是否被采纳、机制是否运转；
   采用度连续 2 期下滑即启动「对接人复盘」，查是内容不对还是人不对。
4. 成果达成管理：成功计划中的每个目标配验收指标与数据源，
   季度逐项对账；未达标项写明归因（我方/客户/环境），
   归因结论影响续约叙事的写法。
5. 价值台账记账口径：每条价值 = 事项 + 金额/效果 + 计算口径 +
   凭证 + 客户确认状态（未确认/已确认）；只有「已确认」可进年度报告；
   每周例会过一遍新增条目，月底封存，不许事后补账。
6. 例会机制：月度内部 CS 例会三问——健康度变了没有、
   台账记了什么、下月节拍有没有断点。

## 输出契约
- 年度成功计划：目标/节拍/验收标准，客户签字版存档。
- 节拍执行台账：各节拍完成记录与断档预警日志。
- 价值台账：符合记账口径的逐条记录，客户确认状态清晰。
- 成功计划的变更、目标的放弃与重谈，由人类与客户共同决定。
