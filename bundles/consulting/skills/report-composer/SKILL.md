# 报告撰写与排版

## 适用场景
- 诊断报告、月度报告、年度价值报告的初稿撰写
- PPT 排版成稿与版式规范执行
- 对外版脱敏改写与检查（C-R5），结论类内容外发必审（C-R2）

## 方法
1. 报告骨架（金字塔先行）：摘要（结论与建议一页读完）→ 背景与范围 → 诊断发现 →
   方案建议 → 实施路径 → 附录（数据明细与口径说明）。先搭骨架再填肉，
   任何一段去掉都不影响主线逻辑。
2. 论证纪律：每条结论挂依据（数据出处/访谈出处/案例参照），引用链可回溯到档案条目；
   红队反证意见在报告中保留呈现位置，不做「一边倒」报告。
3. PPT 版式规范：
   - 一页一观点，标题即结论（行动式标题，不用「市场分析」这类名词式标题）
   - 图表服务论证：每图回答一个问题，图下注明数据来源与口径
   - 版式克制：统一字体字号色系，留白不少于 30%，不堆砌装饰元素
4. 对外版脱敏检查清单（逐项过检）：
   - 员工姓名 → 角色代号；薪酬明细 → 区间或指数化
   - 客户未授权披露的财务明细、供应商信息、未公开战略 → 移除或模糊化
   - 第三方信息（竞对数据、专家观点）→ 标注来源属性与授权范围
   检查记录留痕，未过检不得输出对外版（C-R5）。
5. 版本管理：内部版（全量）与对外版（脱敏）分开存放，版本号与差异说明入档。

## 输出契约
- 报告初稿：骨架完整、标题即结论、每条结论挂引用链，引用记忆随稿输出。
- PPT 成稿：符合版式规范，每页标题可独立成立，图注含来源与口径。
- 对外版：附脱敏检查清单勾选记录；未脱敏件触发 C-R5 拦截，不得绕行。
- 含诊断结论、人员评价、组织建议的版本外发前必审（C-R2）；关键数字无回执标「未核实」。
