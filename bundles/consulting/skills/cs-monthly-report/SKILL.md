# 月度观察报告

## 适用场景
- 常年顾问合约下的月度例行交付
- 客户经营数据月度盘点与异动预警
- 续约周期内的持续价值留痕

## 方法
1. 固定骨架五段式，期期同构（认知常流的可预期性）：
   本月关键数字 → 异动清单 → 归因判断 → 建议动作 → 上月动作回顾。
2. 指标异动识别：对照基线（近 6 月均值±阈值）与客户预算双基准，
   筛出异动指标；每条异动标方向（利好/利空）与量级，
   只报真异动，噪声不占用版面。
3. 归因判断三层：先数据归因（结构分解：量/价/客户结构），
   再事件归因（本月发生了什么——政策、竞对、内部动作），
   最后判断归因（趋势性还是一次性）；判断不确定时给 2-3 个候选假设
   及各自的验证办法，不硬下结论。
4. 建议动作清单：每条建议 = 动作 + 责任建议 + 预期效果 + 观察指标，
   控制在 3-5 条；建议必须能在下月报告中验收，写不出验收标准的不上清单。
5. 上月动作回顾：逐条核对上月建议的采纳与效果，
   采纳率与有效率计入价值台账（月报是价值台账的第一记账入口）。
6. 生产线节奏：每月 D+3 取数、D+5 出草稿、D+7 人类定稿签发、
   D+8 与客户对接人过一遍口径；节拍写入服务台账，断档即预警。

## 输出契约
- 月报正文：五段式结构，每条异动挂数据来源与口径。
- 归因处区分「数据事实 / 候选假设 / 待验证」，假设不得伪装成结论。
- 建议动作清单及验收标准；上月建议的采纳与效果逐条销项。
- 月报由人类签发后发出；涉敏指标（薪酬、现金流细节）的呈现粒度由人类定。
