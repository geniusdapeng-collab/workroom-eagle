# 会前情报简报

## 适用场景
- 澄清会、访谈、汇报会前的客户情报准备
- 线索初查与竞对情报采集
- 只采集公开信息与客户已授权档案，只读不改档

## 方法
1. 明确会议目标：本次会要验证什么假设、拿到什么信息，简报围绕目标组织，不做百科堆砌。
2. 采集三面信息（公开信息 + 档案，只读）：
   - 企业基本面：工商信息、股权结构、规模、产品线、近年经营信号（官网/招聘/新闻）
   - 关键人：决策链成员背景、公开言论、履历风格，推断其关注点
   - 行业动态：近 90 天行业大事、政策变化、竞对动作、上下游信号
3. 推断真实需求：客户说的需求（表层）与行业位置、经营信号交叉比对，
   提出 2-3 个「可能的真实需求」假设，标注每个假设的支持信号与反信号。
4. 生成建议提问清单：按「验证假设」组织，每个问题注明想验证什么、怎么追问；
   问题从面到点，避免会上即兴发挥。
5. 可信度分档：每条信息标注「公开核实（有回执）/ 公开待核实 / 推断」三档，
   推断必须写明推断链条，严禁把推断写成事实。

## 输出契约
- 简报固定五段式：企业基本面 / 关键人 / 行业动态 / 可能的真实需求（2-3 个假设）/ 建议提问清单，阅读时长控制在 10 分钟。
- 每条信息带来源与采集时间；关键数字必须来自检索回执，无回执标「未核实」。
- 涉及个人隐私的信息不采集不呈现，命中即放弃并记录放弃理由。
- 简报只供主理人会前阅读，不直接对客户发出；如需外发版，另行走脱敏与审批流程。
