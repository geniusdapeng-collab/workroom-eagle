# ERP实施辅导

## 适用场景
- ERP 项目已签约，企业缺乏懂实施的内部力量，需要甲方护航
- 蓝图阶段厂商方案与企业实际流程冲突，需要裁决机制
- 历史数据混乱，担心迁移失败导致上线翻车
- 老系统切换风险高，需要并行期与回退方案设计

## 方法
1. 实施治理搭建：明确 steering committee（决策层）、PMO、关键用户
   三层结构；约定变更管理流程——凡超蓝图范围的需求一律走
   CR 评审，防止范围蔓延拖垮项目。
2. 蓝图护航：逐模块评审厂商蓝图（财务/采购/库存/生产/销售），
   重点核查「标准功能 vs 定制开发」边界；坚持「流程适配系统优先，
   定制开发兜底」，定制项须业务负责人签字确认必要性。
3. 数据迁移护航：制定主数据清洗标准（物料/客户/供应商/科目），
   明确冻结时点与责任人；至少两轮迁移演练，核对条目数与
   关键余额，差异必须逐条归因，不接受「整体差不多」（C-R9：
   迁移过程涉及客户/员工数据须按最小必要原则处理）。
4. 上线切换设计：评估「大爆炸 vs 分模块 vs 并行运行」三种策略，
   给出建议与回退预案；并行期一般不超过一个月，避免双倍工作量
   拖垮业务团队。
5. 上线陪跑与稳态化：上线后 4-8 周 hypercare，每日站会处理
   问题清单；结案前完成月结演练与关键用户考核。

## 输出契约
- 蓝图评审意见：逐模块问题清单 + 定制项必要性评审记录。
- 数据迁移报告：清洗规则、演练核对结果、差异归因清单。
- 切换方案：策略建议 + 并行期计划 + 回退预案（触发条件明确）。
- 上线 go/no-go 决策由企业决策层作出；AI 提供就绪度检查清单
  与风险项，不替企业按下启动按钮。
