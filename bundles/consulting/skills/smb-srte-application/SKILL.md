# 专精特新申报

## 适用场景
- 中小企业申报创新型中小企业、专精特新中小企业、小巨人的自评与准备
- 申报被退回后的差距分析与补短板规划
- 从入库培育到梯度晋级的长期路径设计

## 方法
1. 梯度定位：确认企业当前所处梯度（创新型中小企业/专精特新中小企业/
   小巨人/单项冠军）与目标梯度，调取最新年度申报通知中的条件口径，
   注意各地细则差异。
2. 条件逐项自评：按专业化、精细化、特色化、新颖化四类指标逐项比对——
   主导产品收入占比、细分市场年限、研发费用占比、知识产权数量、
   数字化水平、质量管理体系，每项标注「达标/边缘/不达标」及数据出处。
3. 差距与补短板清单：对不达标项给出补强路径（研发费用归集规范、
   知识产权布局、体系认证办理、数字化改造留痕），
   标注每条的周期与成本量级，区分「申报前可补」与「需提前一年布局」。
4. 材料组织与交叉核验：按申报系统清单组织佐证材料——审计报告、
   纳税证明、知产证书、销售合同与发票样本、体系证书，
   核对各材料间数据口径一致（收入、研发费、人数互洽），
   口径冲突处单独列出要求企业澄清。
5. 申报节点管理：梳理申报批次时间、评审流程、公示与有效期管理、
   到期复核要求，形成节点日历。

## 输出契约
- 自评报告：四类指标逐项判定 + 数据出处 + 边缘项说明。
- 补短板清单：差距项 + 补强路径 + 周期成本 + 可补时间窗。
- 材料清单与口径核验表：材料项 + 口径一致性核对结果。
- 节点日历：申报/评审/公示/复核各节点。
- 材料真实性由企业负责，AI 不协助包装或编造数据；
  是否申报、何时申报由企业决策，涉审计与法律事项经专业机构复核（C-R7）。
