# 用工合规体检

## 适用场景
- 企业快速扩张后用工管理粗放，仲裁风险累积
- 拟融资/IPO 前用工合规自查
- 劳动仲裁败诉后系统性整改

## 方法
1. 体检范围确认：覆盖劳动合同 / 社保公积金 / 工时与加班 /
   休假 / 竞业限制 / 规章制度民主程序六大模块，
   明确抽样比例与检查方法（台账核查 + 抽样访谈）。
2. 合同模块扫描：未签/续签逾期、试用期违规、
   条款缺失（工作地点/岗位约定）、主体混同（关联公司用工）
   四类高频问题逐项核对，输出问题清单。
3. 社保模块扫描：缴费基数与工资总额偏离度测算、
   异地用工代缴风险、新业态用工（劳务/外包/实习）定性核查；
   基数缺口测算显化补缴风险敞口。
4. 工时加班模块：标准/综合/不定时工时审批有效性、
   加班审批与记录、加班费支付口径核查，
   用打卡记录与工资条交叉验证。
5. 风险分级：按「败诉概率 × 涉及人数 × 单人金额」
   三维评估，输出红（立即整改）/ 黄（限期整改）/
   蓝（关注）三级清单与整改成本测算。
6. 整改路线：红色项出整改路径与时间表；
   涉及补签、补缴的追溯操作提示各地口径差异，
   必须经执业律师确认后执行。

## 输出契约
- 体检报告：六模块问题清单 + 风险分级表（带金额敞口测算）
  + 整改路线图。
- 全文强制附 C-R7 合规提示：本报告为风险信息整理，不构成法律意见，
  整改动作执行前必须经执业律师审核；各地裁判口径以当地律师意见为准。
- 全部输出触发必审路由（C-R7），未经人工审核不得交付。
- 员工合同、工资、打卡等个人数据按 C-R5 脱敏前置，抽样编号化呈现。
