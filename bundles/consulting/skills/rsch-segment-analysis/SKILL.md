# 市场细分分析

## 适用场景
- 客户资源有限，需在多个客群/区域中做取舍
- 现有「一刀切」打法失效，需按细分定制策略
- 新客增长停滞，需寻找高潜细分赛道

## 方法
1. 选细分变量：B2C 用人口属性+行为+需求场景+价值观四层；
   B2B 用行业+规模+采购模式+数字化水平；变量选择必须与客户
   可执行的营销动作挂钩，不可操作的变量剔除。
2. 数据打底：整合客户 CRM/交易数据、问卷调研、第三方消费数据
   （如尼尔森/QuestMobile 公开报告）；CRM 数据脱敏前置（C-R5）。
3. 聚类分群：用 RFM、K-Means 或阶梯聚类产生候选分群方案，
   比较 3-8 群方案的类间区分度与业务可解释性，选定分群数。
4. 画像构建：每群输出「规模、价值（客单×频次×毛利）、需求指纹、
   触达渠道、决策链」五要素画像，挂数据支撑比例。
5. 吸引力×竞争力矩阵：吸引力（规模×增速×利润空间）与自身竞争力
   （产品匹配×渠道可达×品牌认知）双维打分，落入九宫格。
6. 优先级建议：输出主攻/培育/放弃三档初判与差异化打法要点；
   分群投入决策必审（C-R2）。

## 输出契约
- 细分报告：分群方案+五要素画像+九宫格定位+三档优先级建议。
- 每群规模与价值标注数据口径与置信度，小样本群（n<30）显著标注。
- 涉及客户数据的分析全程脱敏（C-R5），不输出个体级数据。
- 优先级与资源分配为初判，最终取舍必审（C-R2）。
