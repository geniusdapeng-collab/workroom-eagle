# 成本削减专项

## 适用场景
- 利润被成本侵蚀，需系统降本
- 行业下行期过冬式成本管控
- 历次降本「一刀切」后伤筋动骨，需科学方法

## 方法
1. 成本结构拆解：按「料 / 工 / 费 / 期间费用」拆到二级科目，
   计算各科目占收入比与同比变化，数据取自管理报表挂回执；
   区分战略性成本（研发 / 品牌 / 人才）与运营性成本。
2. 降本机会扫描：六方向扫描——采购降价 / 材料替代 /
   工艺优化 / 能耗与物流 / 组织效率 / 费用管控，
   每个机会用「年化收益 × 实施难度 × 副作用风险」三维评分。
3. 机会矩阵排序：收益-难度四象限排序，
   速赢（高收益低难度）先行；副作用风险高的
   （伤质量 / 伤客户 / 伤员工）必须写清代价，不做隐性伤害。
4. 目标设定：按「基准线 × 可达成幅度」定降本目标，
   自下而上认领 + 自上而下校准双向确定，
   目标分解到部门与月份。
5. 不伤筋骨红线：明确「不动清单」——影响产品竞争力的投入 /
   关键人才 / 安全与合规底线支出不纳入降本范围；
   涉及人员优化的部分转 org-layoff-compliance 流程（C-R7）。
6. 防反弹机制：降本成果制度化（预算锁定 / 标准修订 /
   采购合同固化），月度成本复盘会跟踪，反弹即预警。

## 输出契约
- 降本方案：成本结构拆解报告 + 降本机会矩阵（带评分依据）
  + 分部门分月目标表 + 不动清单。
- 每个降本项写清收益测算逻辑与副作用评估。
- 涉及人员优化、供应商压价引发纠纷的内容触发必审（C-R2/C-R7），
  人员事项转专项流程。
- 降本成果以「已实现 / 合同锁定 / 预期」三分栏呈现，不混报。
