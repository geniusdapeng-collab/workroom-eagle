# 岗位体系设计

## 适用场景
- 岗位称谓混乱、同岗不同责同责不同酬
- 员工晋升只能「当官」，缺专业通道
- 薪酬与绩效改革缺岗位体系地基

## 方法
1. 岗位盘点：收集现有岗位清单与实际工作内容，
   用「工作性质 × 价值贡献方式」聚类，
   划分管理（M）/ 专业（P）/ 技术（T）/ 操作（O）等序列。
2. 职级通道设计：每序列设 5-8 级，双通道（管理/专业）并行，
   各层级写清「能力要求 + 贡献标准 + 知识经验」三要素，
   层级间差异必须可观察、可举证。
3. 岗位价值评估：选用海氏（Hay）三要素或美世 IPE 评估法，
   组建评估委员会对所有岗位打分，
   校验评估结果的「跨部门可比性」与「与薪酬现状的偏离度」。
4. 岗位说明书编制：统一模板——岗位使命 / 核心职责（≤8 条）/
   任职资格 / 关键绩效指标 / 汇报关系与协作接口；
   职责描述用「动词 + 对象 + 成果」句式。
5. 套改规则：现有人岗匹配按「就高不就低 + 能力举证」原则套入，
   明确保护期与过渡期安排；
   套改涉及个人定级与薪酬联动，属敏感事项（C-R2 必审）。
6. 动态维护机制：岗位新增/撤并/职责调整的审批流与年度复审节奏。

## 输出契约
- 岗位体系文件：序列表 + 职级标准 + 岗位价值评估结果（带打分明细）。
- 关键岗位说明书样例 ≥ 10 份，模板全岗位适用。
- 套改方案附影响面测算（涉及人数 / 薪酬变动区间），
  个人定级结果交客户管理层逐人确认（C-R2 必审）；
  员工个人数据按 C-R5 脱敏前置，最小可见授权。
