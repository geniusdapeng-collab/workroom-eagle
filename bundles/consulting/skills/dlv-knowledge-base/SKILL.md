# 咨询知识库建设

## 适用场景
- 项目结项后的知识资产入库与结构化
- 新项目启动时的同类案例与方法论检索
- 个体咨询师个人方法体系的长期积累

## 方法
1. 三层资产架构：
   - 方法论层：可迁移的分析框架与流程（如「渠道诊断六步」）
   - 案例层：带情境的项目实录（背景-动作-结果-教训）
   - 模板层：可直接套用的文档骨架（访谈提纲、报告模板、计算表）
2. 入库标准：每条资产必须有摘要（50 字）、适用条件、来源项目、
   验证状态（已复用 N 次 / 待验证）；无适用条件的资产不入库。
3. 脱敏规则：客户名、人名、关键数字区间化（「营收 3-5 亿制造企业」）；
   涉密条款的项目只存方法不存数据；脱敏后须人类复核方可入库。
4. 标签体系：行业 × 议题 × 企业阶段 × 方法类型四维打标，
   每条资产 3-6 个标签；标签词表集中维护，禁止自由造词。
5. 检索与复用：新项目启动强制检索同类案例 Top3，
   复用后在资产页登记「复用记录 + 效果反馈」；
   连续 3 次复用失效的资产降级为「历史参考」。
6. 季度养护：每季度清点一次——高频资产升模板、
   相似资产合并、零检索资产归档。

## 输出契约
- 入库条目：三层分类 + 四维标签 + 摘要 + 适用条件 + 验证状态。
- 检索报告：新项目启动时的同类资产清单及复用建议。
- 复用台账：每次复用的效果反馈，作为方法论迭代的依据。
- 脱敏合规性由人类复核签字；原始敏感数据永不入公共知识库。
