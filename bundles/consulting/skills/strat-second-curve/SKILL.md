# 第二曲线设计

## 适用场景
- 主业增速放缓，需提前布局新增长曲线
- 企业有资源冗余，寻找第二增长引擎
- 已有新业务尝试但多点开花未聚焦

## 方法
1. 见顶信号识别：用五信号清单扫描主业——行业渗透率过半 /
   获客成本持续上升 / 价格战常态化 / 头部集中度过半 /
   核心客群代际迁移；命中 2 条以上即确认启动第二曲线窗口。
2. 候选机会扫描：沿三个同心圆找机会——
   核心能力复用（同能力新市场）/ 客户资产复用（同客户新需求）/
   资产复用（同渠道新供给）；优先内圈，外圈谨慎。
3. 候选筛选：用「市场空间 × 能力匹配 × 时机窗口 × 试错成本」
   四维度打分（每项 1-5 分，写明打分依据），
   筛出 1-2 个候选，宁少勿多。
4. 验证路径设计：按精益创业「假设 → MVP → 验证指标」设计——
   列出该业务的 3 条生死假设，为每条假设设计最低成本验证动作
   与通过/否决标准（如：90 天内付费客户 ≥ 20 家）。
5. 组织与资源隔离：建议新业务独立小团队 + 独立核算 + 独立考核，
   防止主业 KPI 绞杀新业务；明确「监护人」角色与预算上限。
6. 节奏与止损：设定三个检查点（假设验证 / 模式跑通 / 规模复制），
   每个检查点写明继续 / 调整 / 终止的判定标准。

## 输出契约
- 第二曲线方案：见顶信号诊断 + 候选评分表（带依据）+ 验证路径图。
- 生死假设与验证标准逐条列明，未通过即终止，不写「再看看」。
- 资源隔离与独立考核方案涉及现有管理层权责，交客户决策层确认（C-R2 必审）。
- 新业务对主业的冲击评估必须如实呈现，包括不利结论。
