# 现场5S管理

## 适用场景
- 现场脏乱差，找东西靠问、工具靠猜
- 客户审厂在即，现场形象不过关
- 推行过 5S 但「一阵风」，回潮严重

## 方法
1. 示范区选择：选一个典型区域（一条线 / 一个车间）做样板，
   用「前后对比照片 + 数据」建立信心后再推广。
2. 整理（Seiri）：红牌作战——区分「要 / 不要」，
   不要品贴红牌集中处置（移库 / 变卖 / 报废），
   处置规则与审批流写明，报废涉及资产的走财务流程。
3. 整顿（Seiton）：三定原则（定点 / 定容 / 定量）+
   形迹管理 / 划线标识 / 标签系统，
   目标「30 秒内找到任何物品」，用取物计时测试验证。
4. 清扫（Seiso）：清扫即点检——划分清扫责任区，
   清扫标准与点检表合一，异常（漏油 / 松动 / 异响）
   即时挂牌上报，接入设备维护流程。
5. 清洁（Seiketsu）：把前 3S 成果标准化——
   目视化管理标准（颜色 / 标线 / 看板）+ 检查评分表 +
   区域责任人公示，评分表 ≥ 80 分为合格线。
6. 素养（Shitsuke）：班前会 5S 五分钟 / 巡查制度 /
   月度评比与红黑旗；评分与团队激励挂钩，
   挂钩方案避免针对个人的羞辱式公示（C-R2）。

## 输出契约
- 5S 推行方案：示范区验收报告（前后照片对比）
  + 红牌处置记录 + 三定与目视化标准图册。
- 检查评分表与巡查制度模板，评分规则透明。
- 评比激励方案涉及个人与团队评价，公示形式交客户管理层确认（C-R2 必审）。
- 5S 是手段不是目的，交付物必须挂业务指标变化
  （效率 / 质量 / 安全事故）而非只有现场照片。
