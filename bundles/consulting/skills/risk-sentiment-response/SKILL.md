# 舆情处置

## 适用场景
- 品牌关键词在社交平台出现负面聚集时的日常值守
- 突发负面舆情（热搜、大V转发、媒体跟进）的应急处置
- 舆情平息后的复盘与机制完善

## 方法
1. 监测建网：确定监测关键词组（品牌名、产品名、高管名、行业风险词），
   覆盖主流社交平台与垂直社区，区分日常巡检与突发告警两档频率。
2. 舆情定级：按传播量（阅读/转发量级）、情绪烈度（吐槽/声讨/行动号召）、
   参与者权重（普通用户/大V/媒体/监管）、事实属性（属实/部分属实/不实）
   四维定级（关注/响应/紧急），定级依据逐项留痕。
3. 响应策略匹配：关注级以记录与私信沟通为主；响应级准备官方口径，
   在源头平台回应；紧急级启动危机流程（联动 risk-crisis-pr），
   每级明确「回应/不回应」的判定条件，避免逢帖必回的应激反应。
4. 口径草稿准备：回应文案遵循事实-态度-行动三段，逐句标注依据；
   对不实信息准备澄清证据包（截图、数据、时间线），不做情绪化对抗表述。
5. 复盘闭环：每次处置后记录定级准确性、响应时效、舆情走势拐点，
   校准关键词组与定级阈值。

## 输出契约
- 舆情简报：事件概述 + 传播数据 + 情绪与参与者分析 + 定级及依据。
- 响应建议：回应/不回应的判定 + 口径草稿（逐句带依据）+ 发布渠道建议。
- 复盘记录：定级偏差、时效、拐点分析 + 机制调整建议。
- 对外口径由客户决策层审定后发布；涉法律定性表述须经执业律师复核（C-R7）。
- 不做删帖、水军等灰色操作的建议，发现此类需求明确拒绝并提示合规风险。
