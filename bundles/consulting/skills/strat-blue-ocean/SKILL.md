# 蓝海战略

## 适用场景
- 红海竞争利润微薄，寻找价值创新空间
- 新品类定义与商业模式重构
- 成熟业务需要差异化突围

## 方法
1. 价值曲线测绘：列出行业当前竞争的 8-12 个价值要素，
   绘制本公司与主要对手的价值曲线（高低配分），
   配分依据来自客户调研与数据，写明样本与方法。
2. 非客户分析：按蓝海三层非客户框架访谈——
   一层「准非客户」（勉强使用）、二层「拒绝型非客户」、
   三层「未探知非客户」，提炼他们不买账的共同原因。
3. 四步动作框架：对每个价值要素执行
   剔除（行业理所当然但无价值）/ 减少（过度供给）/
   增加（不足供给）/ 创造（行业未提供），
   每个动作写明依据与成本影响。
4. 新价值曲线绘制：基于四步动作画出新价值曲线，
   校验蓝海三特征——重点突出 / 另辟蹊径 / 主题令人信服，
   与对手曲线无明显差异即打回重做。
5. 商业模式校验：用「买方效用 × 战略定价 × 目标成本」顺序校验——
   效用不足回第一步；定价按价格走廊法定；成本倒推不达标
   则通过合作或模式创新降本，不允许牺牲效用硬压成本。
6. 落地障碍预案：预判认知 / 资源 / 动力 / 政治四类组织障碍，
   为每类给出引爆点式突破动作。

## 输出契约
- 价值创新方案：现状价值曲线 + 非客户洞察（带访谈回执）
  + 四步动作表 + 新价值曲线。
- 商业模式三校验结论：效用 / 定价 / 成本逐项过关记录。
- 价格走廊与成本目标的关键假设逐条列明。
- 价值要素的「剔除/减少」若导致现有产品线收缩或人员调整，
  触发必审路由（C-R2/C-R7）。
