# 年度价值报告

## 适用场景
- 常年顾问合约到期前 60-90 天的续约铺垫
- 客户年度经营会上的顾问价值陈述
- 向客户新决策人（换帅/换股东）重新证明价值

## 方法
1. 价值台账取数：从全年价值台账逐条取数，按三类价值归集——
   - 直接价值：可算钱的（降本金额、增收贡献、风险止损），每条挂凭证
   - 杠杆价值：经由客户团队放大的（培养的讲师、建起的机制），挂行为证据
   - 期权价值：避免掉的坏决策（否决的方案、避开的坑），挂当时记录
   只认台账中「已确认」状态的条目，未确认条目不得计入。
2. 证据链下钻：每条价值配三层下钻——结论页（一句话+金额/效果）→
   证据页（数据对比、决议记录、客户确认邮件）→ 原始层（台账条目编号）；
   客户财务/业务负责人可独立复核。
3. 节拍对照：按日/周/月/季节拍回放全年服务流（12 期月报、4 次季会、
   N 次预警响应），用「响应时效 + 采纳率」证明认知常流的存在与质量。
4. 续约叙事编织：三段式——「这一年我们共同做到了什么」（价值）→
   「如果没有这层值守，哪些坑会重演」（对照风险）→
   「下一年最值得拿下的三件事」（续约议程）；议程必须具体到可签约。
5. 反方预演：列出客户可能的三个压价理由（预算、自研、换人），
   每个配回应证据；数字硬伤（算错、重复计）逐条自清。
6. 交付节奏：草稿 → 内部红队 → 对接人口径预沟通 → 正式呈报，
   呈报人与答疑人角色分开。

## 输出契约
- 年度价值报告：三类价值汇总表 + 逐条证据链索引 + 节拍回放 + 续约议程。
- 价值金额一律带计算口径与凭证编号；口径存疑的条目剔除并说明。
- 续约议程落到具体事项与预算区间；最终报价与让步空间由人类决定。
- 报告只陈述已确认价值，不许虚构贡献；夸大即自毁信用。
