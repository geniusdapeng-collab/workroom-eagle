# 二代接班辅导

## 适用场景
- 二代已进入或即将进入家族企业，需要系统化的接班准备
- 接班后出现权威不足、元老不服、决策受阻的困境
- 二代主导新老业务交替时的组织磨合

## 方法
1. 接班能力地图：按行业认知、经营决策、团队管理、财务素养、
   对外关系五个维度评估接班人现状，每维标注「已具备/在成长/
   缺失」三档及评估依据（实际业绩、共事者反馈）。
2. 成长路径设计：按「基层轮岗-项目负责人-业务负责人-全面接管」
   阶梯设计历练路线，每阶段明确要证明的能力、考核标志与建议时长，
   反对空降式直接掌权。
3. 元老关系策略：盘点元老类型（功勋型/实权型/观望型），
   给出差异化的相处与授权策略——尊重历史贡献、明确新边界、
   用增量业务建立信任，避免一上来动存量权力结构。
4. 权威建立路线：识别「立威战场」——选一个边界清晰、可见度高、
   胜算大的业务战场打出第一场胜仗，用业绩而非身份建立权威；
   同时梳理创始人背书的使用节奏（早期借重、逐步淡出）。
5. 冲突预警与调解素材：记录接班过程中的关键冲突事件，
   整理事实时间线与各方诉求，供家族会议或外部顾问调解使用。

## 输出契约
- 能力地图：五维评估 + 三档标记 + 依据出处。
- 成长阶梯计划：阶段 + 能力目标 + 考核标志 + 建议时长。
- 元老关系策略卡：类型分析 + 差异化策略 + 禁忌动作。
- 立威战场分析：候选战场对比 + 胜算评估依据。
- 人员任免建议命中敏感类目，强制红队 review（C-R2）；
  成长节奏与人事安排由接班人与家族共同决定。
