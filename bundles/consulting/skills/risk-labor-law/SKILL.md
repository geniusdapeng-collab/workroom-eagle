# 劳动法风险防控

## 适用场景
- 企业裁员、组织优化方案出台前的劳动法风险扫描（敏感类目，必审）
- 招聘流程、劳动合同、规章制度合法性的自查
- 劳动仲裁发生前的证据固定与应对素材准备

## 方法
1. 全周期分断扫描：招聘（歧视性条款、Offer 效力、试用期约定）、
   在职（工时与加班、社保公积金、调岗调薪程序、规章制度民主程序）、
   离职（解除理由、补偿金口径、竞业限制、离职交接）三段分别列检查项。
2. 证据链核查：对每个风险点核查证据是否成立——合同文本、考勤记录、
   工资流水、公示记录、签收记录；证据缺失即标「举证风险」。
3. 解除场景推演：对拟解除人员逐个列出法定解除路径（协商一致/过失性/
   非过失性/经济性裁员）的适用条件、程序要求与补偿成本区间，
   不替客户选择路径，只列各路径的成立要件与风险。
4. 风险定级与敏感路由：涉及裁员方案、人员评价的内容一律命中敏感类目，
   强制红队 review 并注明命中理由（C-R2）；高风险个案单独建卡跟踪。
5. 素材准备止于整理：仲裁应对仅做时间线整理、证据清单、法条索引，
   不出具「胜诉率判断」等法律意见。

## 输出契约
- 风险清单：每条 = 周期阶段 + 风险描述 + 对应法条 + 证据状态 + 定级。
- 解除路径对照表：各路径成立要件、程序步骤、补偿成本区间，均附法条出处。
- 合规提示段落必备：本内容不构成法律意见，个案处理前须经执业律师复核（C-R7）。
- 裁员/人员评价类产出强制走 C-R2 必审路由；是否解除、如何解除留给客户决策。
