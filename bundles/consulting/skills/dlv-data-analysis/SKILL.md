# 咨询数据分析

## 适用场景
- 客户经营数据、财务数据、调研数据的分析解读
- 月报/季报中的指标异动归因
- 方案效果的前后对比验证

## 方法
1. 数据体检先行：核对口径（时间窗、统计主体、计算公式）、
   完整性（缺失率）、一致性（跨表同一指标是否相等）；
   口径存疑的指标先标「待确认」再分析，不得带病运算。
2. 描述层：用分布（分位数）替代单看平均数，用同环比 + 三年趋势
   定位「现在在哪」；识别结构性变化（占比迁移）而非只看总量。
3. 诊断层：异动归因三步——拆结构（量/价/结构三因子分解）、
   找拐点（异动从何时开始、对应什么事件）、做对照
   （有对照组优先差分，无对照组用同类企业基准）。
4. 预测层：仅在数据足够时给区间预测（标注假设与外推风险），
   小样本或高波动场景只给情景推演（乐观/基准/悲观），不给点估计。
5. 可视化纪律：一图一信息；比较用条形、趋势用折线、结构用堆积，
   慎用饼图与双轴；坐标轴不截断，异常值必须标注原因。
6. 结论回挂证据：每个分析结论标注数据来源、口径、样本量，
   与访谈/档案证据三角互证。

## 输出契约
- 分析底稿：口径说明 + 体检结果 + 三层分析过程，可复算。
- 异动归因表：异动指标 × 归因假设 × 证据强度 × 待补数据。
- 预测一律带假设声明与风险提示，情景推演不伪装成精确预测。
- 数据与回执/原始凭证不一致即挂起；最终取数决策权留给人类。
