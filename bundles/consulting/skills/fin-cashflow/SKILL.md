# 现金流管理

## 适用场景
- 有利润没现金，资金链紧绷
- 应收账款越滚越大，回款失控
- 付款节奏混乱，常现兑付危机
- 需要建立资金预警与滚动预测机制

## 方法
1. 现金周期（CCC）测算：CCC = 存货周转天数 + 应收账款周转天数 − 应付账款周转天数，
   与行业基准对比定位短板环节；CCC 每缩短一天释放的资金量 = 年营收 / 365 量化呈现。
2. 13 周滚动资金计划：按周列示期初余额 + 经营收支 + 投融资收支 = 期末余额，
   未来 4 周用确定性口径（合同/账期），5-13 周用概率口径；
   最低安全余额 = 1.5 倍月固定支出设为红线。
3. 应收账款治理：按账龄（30/60/90/180 天+）分层，
   「逾期率 = 逾期金额 / 应收总额」与「DSO」双指标监控；
   客户信用分级（A/B/C）匹配账期与额度，超额度发货需特批。
4. 应付账款策略：利用账期但不伤信用，核心供应商保付款优先级；
   争取「早付折扣」时计算年化收益率 = 折扣率 /（账期 − 提前天数）× 365，
   高于资金成本则采纳。
5. 预警与预案：资金缺口预测触红线即启动预案菜单
   （催收加速/付款协商/授信动用/股东借款），预案分级并明确触发条件。

## 输出契约
- CCC 诊断卡：三环节天数 + 行业基准 + 缩短一天的量化收益。
- 13 周滚动资金计划表：周粒度，红线标注，口径（确定性/概率）分列。
- 应收账龄表 + 客户信用分级规则（额度与账期挂钩）。
- 应付策略表：供应商优先级 + 早付折扣年化测算。
- 资金预案菜单：触发条件/动作/责任人；重大融资与付款展期决策留客户。
