# 运营效率诊断

## 适用场景
- 交付周期长于同行，客户投诉交期
- 质量返工多，成本侵蚀利润
- 扩产前需确认现有流程是否已跑顺

## 方法
1. 流程测绘：选 2-3 条核心流程（如订单到交付、新品上市），
   用价值流图（VSM）记录每工序的加工时间、等待时间、
   在制品数量；数据以现场观察+系统日志双源核实。
2. 周期分解：把总周期拆为「增值时间/必要非增值/纯等待」，
   计算流程效率比（增值时间÷总周期），多数企业该值 <20%。
3. 一次通过率：统计各环节 FPY（First Pass Yield）与累计直通率
   RTY，返工点按频次×单次返工成本排序，定位质量黑洞。
4. 瓶颈确认：用利用率>90% + 上游在制品堆积 + 下游停工待料
   三重证据确认瓶颈工序，区分「真瓶颈」与「假瓶颈（计划不匀）」。
5. 损失归因：按设备故障/换型等待/缺料/质量返工/计划变更
   五类归集停机与等待损失，每类量化到金额。
6. 改善输出：效率地图+损失排序+改善优先级（速赢/项目制/技改）；
   涉及设备投资与人员定编的建议必审（C-R2）。

## 输出契约
- 价值流图：工序级时间分解+流程效率比+数据采信方式说明。
- 质量报告：FPY/RTY+返工成本排序表。
- 改善清单：按投入产出排序，速赢项（30 天内）单独标注。
- 技改投资与定编调整建议必审（C-R2），测算假设透明可挑战。
