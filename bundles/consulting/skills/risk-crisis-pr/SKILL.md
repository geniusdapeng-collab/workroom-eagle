# 危机公关预案

## 适用场景
- 产品质量、安全事故、高管负面等突发事件发生前的预案建设
- 危机发生后的紧急响应与声明起草
- 危机平息后的复盘与预案迭代

## 方法
1. 危机情景库建设：按行业梳理高发危机情景（产品安全、服务事故、
   员工纠纷、数据泄露、高管言论、监管处罚），每类预设触发信号与信息来源。
2. 危机分级定标：按影响范围（个体/群体/公众）、事实清晰度（已证实/
   待核实/谣言）、可修复性三维度定级（蓝/黄/橙/红），每级明确
   决策人、响应时限与资源调用权限。
3. 黄金4小时流程：0-1小时事实核查与定级、1-2小时决策小组定调
   （认/否/缓）、2-4小时首声发出；流程中明确「谁先说话、说什么、
   在哪说」，禁止多头发声。
4. 声明口径框架：提供声明骨架——事实陈述（已核实的）+ 态度表达 +
   行动承诺 + 信息更新渠道；草稿标注每句话的事实依据，
   未核实信息不得写入。
5. 复盘机制：危机平息后按时间线复盘响应得失，更新情景库与分级标准，
   复盘记录归档可检索。

## 输出契约
- 危机分级表：级别 + 判定标准 + 决策人 + 响应时限。
- 响应流程卡：黄金4小时逐时段动作与责任人。
- 声明草稿：逐句标注事实依据，未核实内容用占位符标明。
- 对外声明的最终措辞与发布时机由客户决策层决定；涉法律责任表述
  须经执业律师复核（C-R7）。
