# 年度经营计划

## 适用场景
- 年底编制下一年度经营计划与预算
- 战略目标需要翻译为可执行的年度目标与行动
- 计划年年做年年落空，需重建计划管理机制

## 方法
1. 目标设定：从三年规划战役卡承接年度目标，
   用「保底 / 合理 / 挑战」三档设定收入、利润、现金流目标，
   三档各自的达成概率与依据必须写明。
2. 目标分解：按 OGSM 框架（目的-目标-策略-衡量）自上而下分解，
   公司级 O/G → 部门级 S/M → 关键行动计划，
   用平衡计分卡（BSC）四维度校验目标结构不缺腿。
3. 预算联动：目标与预算双向校验——收入目标对应的获客成本、
   产能、人员编制是否已在预算中体现；预算缺口超 10% 的科目
   列出「增投 / 降目标 / 提效率」三个选项。
4. 季度里程碑：把年度目标拆为四个季度的里程碑节点，
   每个节点定义「可验证的交付物」而非「做了什么动作」，
   Q1 里程碑颗粒度最细，逐季递减。
5. 经营分析会机制：设计月度经营分析会模板——
   固定议程（达成回顾 / 偏差归因 / 对策与资源请求）、
   偏差归因强制区分「外部因素 / 策略失误 / 执行不力」。

## 输出契约
- 年度经营计划书：三档目标 + OGSM 分解表 + 预算联动表 + 季度里程碑。
- 每个目标数字挂测算依据（历史数据 / 市场假设 / 产能约束）。
- 月度经营分析会模板与偏差归因表随计划一并交付。
- 目标分解到部门后涉及部门负责人的权责与考核，交客户管理层确认（C-R2 必审）。
