# 交付周期压缩

## 适用场景
- 交付周期比竞对长，丢单于交期
- 订单准交率低，销售不敢接急单
- 周期被「惯例」固化，没人知道真实瓶颈

## 方法
1. 周期分解测绘：把订单到交付总周期按
   「订单处理 / 采购 / 生产 / 检验 / 物流」分段计时，
   区分增值时间与等待时间，数据现场采集挂回执——
   通常等待时间占 70% 以上。
2. 瓶颈定位：用 TOC 五步法——识别瓶颈（在制品堆积点 +
   设备负荷率验证）→ 挖尽瓶颈（不停机 / 不空转 /
   只做合格品）→ 迁就瓶颈（非瓶颈让路）→ 提升瓶颈 → 循环。
3. 并行工程：串行流程改并行——订单评审与技术准备并行 /
   长周期物料预测性采购 / 模块化设计支持并行装配，
   写明并行带来的风险与闸门控制。
4. 排产规则化：用有限产能排产替代经验派单，
   明确排产规则优先级（交期 / 换型损失 / 瓶颈利用率），
   急单插单规则量化（如插单 ≥ X% 触发重排评审）。
5. 快速换型（SMED）：换型作业区分内部 / 外部作业，
   内部转外部、作业标准化，目标换型时间减半，
   改善前后秒表实测对比。
6. 承诺与监控：周期目标分阶段（如 30 天降 20%），
   上线准交率与周期双指标看板，周会检讨。

## 输出契约
- 周期压缩方案：分段周期测绘表（带数据回执）+ 瓶颈分析报告
  + TOC 改进清单 + 排产规则书 + SMED 改善记录。
- 压缩目标按阶段给出测算依据，不承诺无依据数字。
- 排产规则变更影响交付承诺与商务条款的内容交客户管理层确认（C-R2）。
- 并行工程的风险闸门清单单独列明，质量风险不得为周期让步。
