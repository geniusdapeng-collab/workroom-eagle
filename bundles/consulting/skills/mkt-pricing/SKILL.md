# 定价策略

## 适用场景
- 新品上市定价或老品调价
- 价格战压力下需重建定价逻辑
- 折扣随意、价格体系混乱
- 多 SKU 价格带设计

## 方法
1. 价值定价测算：以客户可量化收益为锚——
   「价值锚 = 客户节省成本 + 增加收入 − 替代方案成本」，定价取价值锚的 1/3-1/10 区间，
   价值测算必须列出假设与数据来源，不接受拍脑袋数字。
2. 竞品价格带扫描：AI 批量抓取竞品公开报价（官网/电商/招投标公示），
   绘制价格带分布图，识别空档价格位与红海价格位；样本量与抓取时点注明。
3. 价格弹性模拟：用历史调价数据或问卷（PSM 价格敏感度测试，样本≥200）估算弹性系数，
   模拟「涨价 x% → 销量变化 ≈ −x × 弹性%」对毛利的影响，输出 3 档价格方案的毛利对比。
4. 价格带与 SKU 架构：按「引流款/利润款/形象款」三层设计价格带，
   相邻 SKU 价差建议 20-50%，锚点款抬高整体价格感知。
5. 折扣纪律：折扣权限分级表（销售/总监/CEO 各可批折扣上限），
   所有报价与折扣方案必审（C-R6）；例外折扣必须留痕并月度复盘折扣率分布。

## 输出契约
- 定价测算表：价值锚计算过程 + 假设清单 + 数据来源回执。
- 竞品价格带分布图 + 卡位建议（注明样本与时点）。
- 弹性模拟结果：3 档价格方案的销量/毛利敏感性对比。
- 价格带架构表：SKU 分层/价差/角色定位。
- 折扣权限表 + 例外折扣审批流；一切报价折扣必审（C-R6），最终定价权归客户。
