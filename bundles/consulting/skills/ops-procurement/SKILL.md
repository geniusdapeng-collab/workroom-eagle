# 采购策略优化

## 适用场景
- 采购成本高企，降价只靠压供应商
- 供应商数量庞杂，管理粗放
- 关键物料供应风险集中

## 方法
1. 支出分析：全量采购支出按品类 / 供应商 / 部门三维透视，
   数据清洗口径写明，识别「品类集中度 × 供应商集中度」风险。
2. 品类策略：卡拉杰克矩阵（供应风险 × 采购金额）四象限——
   杠杆品类（竞争招标降本）/ 瓶颈品类（保供优先）/
   关键品类（战略合作）/ 常规品类（流程简化），
   每品类输出策略卡。
3. 供应商分级：按「质量 / 交付 / 成本 / 技术 / 服务」
   五维绩效评分（数据挂回执），分战略 / 优选 / 合格 /
   淘汰四级，淘汰与引入规则写明。
4. 成本拆解：对重点品类做成本模型（Should Cost）——
   原材料 / 加工 / 管理 / 利润逐项拆解，
   用大宗商品指数与工时数据交叉验证，识别降本空间。
5. 谈判弹药包：每品类编制谈判包——支出数据 / 成本模型 /
   替代供应商报价 / 量价组合方案 / 让步阶梯，
   谈判目标分「理想 / 可接受 / 底线」三档。
6. 合规与廉洁：采购权限与审批流、供应商关联关系申报、
   招标程序合规清单；涉商业贿赂风险点提示法务审（C-R7）。

## 输出契约
- 采购优化方案：支出透视报告 + 品类策略卡 + 供应商分级表
  + 重点品类成本模型与谈判弹药包。
- 成本模型的参数假设逐条列明；供应商绩效数据挂出处。
- 供应商淘汰建议附过渡方案，汰换决策交客户采购委员会（C-R2 必审）。
- 供应商商务信息按密级管理；采购人员关联申报属敏感信息，
  最小范围知悉（C-R5）。
