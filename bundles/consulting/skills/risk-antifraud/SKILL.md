# 反舞弊体系

## 适用场景
- 采购、销售、报销等高危环节的舞弊风险梳理
- 举报渠道与举报人保护机制的建设
- 舞弊线索发生后的初步核查与调查素材准备

## 方法
1. 舞弊风险地图：按采购到付款、销售到收款、费用报销、库存管理、
   人事薪酬五类高危流程，逐项列出典型舞弊手法（围标串标、飞单、
   虚假报销、吃回扣、阴阳合同），标注现有控制的薄弱点。
2. 红旗指标设计：为每类手法设计数据化预警信号——供应商集中度异常、
   中标价贴边、报销时间聚集、退货率异常、同 IP 多账号等，
   阈值先定后测，预警只提示「异常」不指认「舞弊」。
3. 举报机制设计：梳理举报渠道（热线/邮箱/线上表单）、受理与分流流程、
   举报人保护措施与反报复条款，明确受理后的保密义务与信息知悉范围。
4. 调查流程支持：线索核查阶段做公开信息与内部数据的交叉比对、
   时间线整理、访谈提纲草拟；所有涉及个人信息的内容脱敏处理（C-R5），
   不做电子取证、监听等越权操作的建议。
5. 处置与整改衔接：查证素材移交法务/审计负责人定性；涉刑线索提示
   移送司法机关的边界，整改端回到内控缺陷修复（联动 risk-internal-audit）。

## 输出契约
- 舞弊风险地图：流程 + 手法 + 现有控制 + 薄弱点 + 红旗指标。
- 预警清单：异常记录 + 触发指标 + 数据出处，只列异常不定性。
- 调查素材包：时间线 + 数据交叉比对结果 + 访谈提纲，PII 已脱敏（C-R5）。
- 舞弊定性、处分决定、移送司法均由客户法务/审计负责人决策；
  涉法律责任表述须经执业律师复核（C-R7）。
