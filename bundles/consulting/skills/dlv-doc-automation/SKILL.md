# 交付文档自动化

## 适用场景
- 月报、季报、例会材料等周期性文档的批量生产
- 结构稳定、数据可回填的诊断/方案文档章节
- 多客户并行时的同名文档批量生成

## 方法
1. 文档分型：把交付物分为三类——全自动化（结构+数据皆稳定，如月报）、
   半自动化（骨架稳定、判断需人工，如异动归因）、
   不可自动化（结论与叙事，如年度策略）；只对前两类建生产线。
2. 模板建设：全自动化文档做「模板 + 数据槽位」，
   槽位绑定档案字段（客户、期间、指标口径），一槽一源；
   模板版本化管理，改动留痕。
3. 数据回填校验：自动填充后跑三道校验——
   槽位完整性（无空槽）、口径一致性（与档案源字段比对）、
   合理性（环比超阈值标黄）；任何一道不过即转人工。
4. 半自动化协同：AI 产出「事实层」（数据、异动清单、候选归因），
   人类补「判断层」（归因定调、建议动作）；界面与文档中明确分层，
   事实层不许混入未标注的推测。
5. 生产线度量：记录每类文档的自动化率、人工修改率、差错回退率；
   连续 3 期差错回退率 >5% 的模板下线检修。
6. 变更管理：指标口径或档案结构变更时，先改槽位映射再跑样张验证，
   确认无误后才允许批量生成。

## 输出契约
- 模板档案：模板版本 + 槽位-字段映射表 + 校验规则清单。
- 生成记录：每期文档的校验结果与人工修改点，可追溯。
- 自动化边界清单：哪些文档/章节禁止自动生成，明示给团队。
- 自动产出只到「待签发」状态；对外发出必须经人类签发，无一例外。
