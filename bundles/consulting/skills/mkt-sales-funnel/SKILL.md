# 销售漏斗优化

## 适用场景
- 线索多但成交少，不知卡在哪一环
- 销售预测长期不准，拍脑袋报数
- 销售话术因人而异，新人上手慢
- CRM 数据有了但没转化成管理动作

## 方法
1. 漏斗口径统一：定义各阶段进入/退出标准（线索→MQL→SQL→商机→成交），
   每阶段给出可核验的判据（如 SQL = 有预算+有决策人+有时间表），杜绝阶段注水。
2. 逐级转化率诊断：计算「阶段转化率 = 进入下阶段数 / 本阶段数」与平均停留时长，
   与自身历史及行业基准对比，定位转化率最低 + 停留最长的瓶颈环节。
3. 瓶颈归因：AI 批量分析丢单原因记录与销售通话/聊天记录（脱敏后），
   输出丢单原因 TOP5 及占比；区分「线索质量问题」与「销售动作问题」。
4. 话术优化：抽取 TOP 销售的成交对话做结构拆解（开场/需求挖掘/异议处理/促成），
   沉淀话术库；AI 对全员对话做质检评分，输出个人短板清单。
5. 漏斗预测：按「加权预测 = Σ（商机金额 × 阶段历史成交率）」滚动预测，
   预测与实际偏差 >20% 触发复盘；数据全部挂 CRM 回执。

## 输出契约
- 漏斗口径定义表：各阶段进入/退出判据，销售全员对齐。
- 诊断报告：逐级转化率/停留时长/基准对比/瓶颈定位。
- 丢单原因 TOP5 榜单（样本量与脱敏说明注明）。
- 话术库 + 个人质检短板清单。
- 加权预测表 + 偏差复盘记录；人员评价与奖惩建议必审（C-R2），定夺权归客户。
