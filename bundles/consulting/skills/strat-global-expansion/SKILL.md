# 出海战略规划

## 适用场景
- 国内增长见顶，评估出海方向
- 已有零散海外订单，需系统化出海布局
- 出海首战受挫，复盘重选市场或模式

## 方法
1. 出海动因澄清：区分「市场拉动 / 成本推动 / 客户跟随 / 避险分散」
   四类动因，动因决定市场选择与进入模式；
   动因不清先回战略澄清工作坊。
2. 目标市场筛选：建市场评分卡——市场规模 / 增速 / 竞争烈度 /
   准入壁垒 / 文化与制度距离 / 汇率与政策风险，
   六维打分（挂数据来源），筛出 2-3 个首发市场，拒绝全面铺开。
3. 进入模式比较：按「控制度 × 投入度 × 风险」比较
   出口 / 代理 / 合资 / 独资 / 跨境并购五模式，
   输出比较矩阵并给出首选与备选，写明选择理由。
4. 本地化路径：按产品本地化 → 营销本地化 → 组织本地化 →
   供应链本地化四阶段排布，每阶段列触发条件
   （如：单国收入超 X 万即设本地团队）。
5. 合规风险清单：覆盖数据合规（如 GDPR 类）、税务架构、
   劳动用工、知识产权、外汇管制五类，逐项标注风险等级；
   明确本清单不构成法律意见，落地前聘请当地执业律师（C-R7）。
6. 试点与复盘：首发市场设 6-12 个月试点期，
   定义单位经济模型（UE）转正为通过标准，未达标即复盘模式。

## 输出契约
- 出海蓝图：动因判断 + 市场评分卡（带数据回执）+ 进入模式比较矩阵。
- 本地化四阶段路线图，每阶段触发条件量化。
- 合规风险清单附 C-R7 合规提示段落；各国法规条目注明信息时点，
  法规变动需以当地律师意见为准。
- 市场选择与重资产投入决策交客户董事会裁定（C-R2 必审）。
