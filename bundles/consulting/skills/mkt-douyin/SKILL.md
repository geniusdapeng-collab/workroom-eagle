# 抖音运营

## 适用场景
- 从 0 搭建抖音获客/带货体系
- 短视频有播放无转化
- 直播间流量波动大、转化率低
- 本地商家需打通团购与到店

## 方法
1. 账号定位与人设：明确「目标客群/内容价值/变现路径」三要素，
   对标账号拆解（内容结构/更新频率/变现方式），AI 批量分析同类账号
   高完播视频的共性（时长/开头钩子/BGM 类型/字幕密度）。
2. 脚本工业化：黄金 3 秒开头（冲突/悬念/利益点）+ 中段价值密度 +
   结尾行动指令；脚本模板化后 AI 批量生成初稿，人工精修网感与真实感；
   每条视频挂一个核心指标（完播率/互动率/转化率）复盘。
3. 直播转化漏斗：按「进房→停留→互动→点击→下单」五层诊断，
   话术分「憋单/讲解/催单/售后预告」四段设计；
   排品策略（引流款/利润款/宠粉款）与过款节奏明确到分钟级脚本。
4. 本地生活打法：POI 地址绑定 + 团购套餐设计（引流套餐让利换到店）+
   达人探店铺量；到店核销率 = 核销数 / 售出数作为核心口径，
   团购让利与折扣必审（C-R6）。
5. 投流与合规：千川/本地推投流按 ROI 分计划管理，素材衰退期及时更换；
   广告法敏感词（最/第一/治疗类）自动拦截，对外发布内容必审（C-R2）。

## 输出契约
- 账号定位卡：客群/价值/变现路径 + 对标拆解表。
- 脚本模板库：3 秒钩子清单 + 结构模板 + 复盘指标口径。
- 直播作战手册：漏斗诊断 + 分钟级脚本 + 排品表。
- 本地生活方案：POI/套餐/达人清单；套餐折扣必审（C-R6）。
- 对外发布内容必审（C-R2）；投流预算与人设方向留客户决策。
