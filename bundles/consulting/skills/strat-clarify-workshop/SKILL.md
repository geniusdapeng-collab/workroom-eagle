# 战略澄清工作坊

## 适用场景
- 高管团队对战略方向存在分歧，需要结构化收敛
- 新财年前的高层战略共识会与务虚会设计
- 战略复盘后发现「会上同意、会后各干各的」，需重做共识

## 方法
1. 会前访谈与议题树搭建：对每位核心高管做 45 分钟一对一访谈
   （统一提纲：行业判断 / 公司胜负手 / 最担心的三件事），
   用议题树（Issue Tree）把分歧拆成「事实分歧 / 目标分歧 / 路径分歧」三类。
2. 材料预制：按「数据先行」原则准备会前阅读包——行业规模与增速回执、
   客户访谈摘要、竞对动向对照表；每份材料标注数据来源与口径，
   不接受无出处数字上会。
3. 分歧点预判：绘制「立场地图」（谁支持 / 谁反对 / 谁观望 + 各自利益关切），
   对预计僵持议题预置 2-3 个折中方案与决策规则（投票 / 一把手裁定 / 试点验证）。
4. 现场流程设计：按「对齐事实 → 对齐目标 → 对齐路径 → 承诺行动」四段推进，
   每段设收敛产出物（事实清单 / 目标排序 / 路径选择 / 行动承诺表），
   配计时与停车机制（Parking Lot 暂存跑题议题）。
5. 输出共识纪要：记录「已共识 / 待验证 / 存分歧」三栏，
   存分歧项必须写明决策人、决策时限与验证方式，禁止留白。

## 输出契约
- 会前包：议题树 + 立场地图 + 数据阅读包（全部数字挂出处回执）。
- 共识纪要：三栏清单 + 行动承诺表（责任人 / 时限 / 验证方式）。
- 涉及对高管个人的评价性判断只作过程参考，不进正式交付物（C-R2 必审）。
- 工作坊收敛的方向性结论交客户一把手最终裁定，AI 不替客户做战略选择。
