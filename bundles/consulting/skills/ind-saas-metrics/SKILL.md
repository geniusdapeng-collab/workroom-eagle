# SaaS指标体检

## 适用场景
- SaaS 公司融资/年报前需要一套口径严谨的指标体检
- 增长放缓，需要定位是获客、留存还是变现环节出问题
- 并购尽调中核实对方自报指标的水分

## 方法
1. 口径先统一（体检前置步骤，口径不合全部白算）：
   MRR 只含经常性订阅收入，一次性实施费、硬件、定制开发必须剔除；
   确认收入与回款分开列，回款口径会高估健康度。
2. 增长与留存双维：
   - NDR（净收入留存）=（期初 MRR + 扩购 - 降级 - 流失）÷ 期初 MRR，
     > 110% 优秀、< 100% 说明老客户盘在漏水
   - GRR（毛收入留存，不含扩购）< 85% 时产品粘性有根本问题，
     靠增购掩盖流失的 NDR 要拆穿
3. 获客效率：CAC 回收期 = CAC ÷（月均 ARPA × 毛利率），
   SMB 应 < 12 个月、企业级可放宽至 18-24 个月；
   LTV/CAC < 3 说明增长不经济，烧钱换规模不可持续。
4. 综合健康：Rule of 40（增长率% + 利润率% ≥ 40）判断增长质量；
   Burn Multiple（净烧钱 ÷ 净新增 ARR）> 2 说明资本效率差。
5. 常见水分排雷：把多年合同全额计入当期 ARR、
   免费试用计入客户数、流失口径用「主动退订」而非「到期未续」——
   三种手法逐项排查并在报告中标注调整前后差异。

## 输出契约
- 指标口径声明：MRR/ARR/流失的定义与剔除项逐项列明。
- 五维体检表：NDR/GRR、CAC 回收期、LTV/CAC、Rule40、Burn Multiple
  各自数值 + 基准线 + 达标判定。
- 水分调整报告：发现的口径问题及调整前后对比。
- 改善抓手排序：按对 NDR 与 CAC 回收期的边际贡献排列。
- 对外披露的指标措辞由客户与审计/法务确认，本技能只出内部测算。
