# 品牌焕新

## 适用场景
- 老品牌客群老化，年轻消费者认知度低，增长乏力
- 品牌有历史资产但形象陈旧，需要系统焕新而非换 logo
- 焕新动作做过几轮没效果，需要诊断失败根因

## 方法
1. 品牌资产盘点：先分清「要保留的资产」与「要卸掉的包袱」——
   品牌知名度、品质信任、经典单品是资产；
   过时形象、老化渠道、低价心智是包袱。焕新失败首因是把资产当包袱扔了。
2. 双客群结构测算：老客贡献占比 > 60% 时，
   焕新节奏必须「老产品线保基本盘 + 新产品线打新客」双线并行，
   激进转型丢老客、新客没接住，是焕新最大死法。
3. 产品焕新先行：年轻化本质是产品年轻化——
   大单品策略（1 个 hero SKU 承载新定位）、
   规格/口味/包装按年轻场景重做，只换视觉不换产品 = 换汤不换药。
4. 传播焕新匹配：新客群触点（短视频、种草平台、线下快闪）
   与内容语气重做，但品牌核心识别（名称、标志色、经典元素）保持稳定；
   联名与代言只负责破圈，承接还得靠产品。
5. 焕新节奏三阶段：试点渠道验证（3-6 个月，看新客占比与复购）→
   产品线扩展 → 全渠道形象切换；每阶段设止损线，
   试点期新客复购率不达标即回调，不硬推。

## 输出契约
- 品牌资产/包袱清单：保留项与改革项分列 + 判断依据（调研/销售数据）。
- 双客群结构测算：老客流失风险敞口 + 双线并行资源分配建议。
- 焕新方案：大单品定义、产品线规划、传播触点与内容方向。
- 三阶段节奏表：各阶段验证指标（新客占比、复购率）与止损线。
- 商标变更、代言合同等法律事项交专业机构，本技能不出具意见（C-R7）。
