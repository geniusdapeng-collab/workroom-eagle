# 商业计划书

## 适用场景
- 融资 BP 从 0 撰写或推倒重写
- BP 内容堆砌但逻辑断裂、无说服力
- 财务预测拍脑袋，被投资人一问就穿
- 路演问答准备不足，现场翻车

## 方法
1. BP 十二页结构：封面/痛点/解决方案/产品演示/市场规模（TAM-SAM-SOM）/
   商业模式/竞争格局/牵引力/团队/财务摘要/融资需求/附录，
   一页一个观点，标题即结论。
2. 市场规模测算：TAM-SAM-SOM 三层漏斗，自上而下（行业报告）与
   自下而上（目标客户数 × 客单价）双法交叉验证，差异 >50% 必须解释；
   引用数据注明来源与年份。
3. 财务模型：三年预测按「驱动因子 → 收入 → 成本 → 现金流」搭建，
   收入预测必须可拆解到客户数/客单价/复购等可验证假设；
   做保守/基准/乐观三情景，基准情景的假设逐个标注依据。
4. 竞争格局呈现：用「能力维度 × 竞品」对比矩阵或定位地图，
   只讲可核验的差异，不贬低竞品；AI 批量整理竞品公开信息（官网/财报/招聘）佐证。
5. 路演问答库：预判 30+ 尖锐问题（护城河/天花板/烧钱速度/团队短板），
   每题准备「30 秒版 + 3 分钟版」回答，数据类问题答案挂模型假设页。

## 输出契约
- BP 成稿：十二页结构，标题即结论，数据全部注明来源。
- 市场规模页：双法测算 + 交叉验证差异解释。
- 财务模型：三情景 + 假设清单，假设可追溯到访谈/数据回执。
- 竞争对比矩阵：仅列可核验事实。
- Q&A Bank：30+ 题双版本回答；BP 对外发送范围与融资条款决策留创始人。
