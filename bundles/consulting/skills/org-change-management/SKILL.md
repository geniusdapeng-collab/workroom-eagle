# 变革管理

## 适用场景
- 战略转型、架构调整、系统上线等重大变革推行
- 变革方案正确但推不动、阳奉阴违
- 并购后整合变革

## 方法
1. 变革影响评估：用「影响范围 × 影响深度」矩阵盘点
   受影响群体，对每群体评估「利益得失 / 能力要求变化 /
   身份认同冲击」，输出影响清单。
2. 阻力地图绘制：按 ADKAR 五要素（认知 / 渴望 / 知识 /
   能力 / 强化）诊断各群体卡点，区分
   「不知道 / 不愿意 / 不能够」三类阻力，对策完全不同。
3. 关键人策略：绘制利益相关者权力-态度矩阵，
   识别「关键支持者 / 摇摆者 / 公开反对者 / 隐性抵抗者」，
   对每类人定策略（借力 / 争取 / 中立化 / 隔离），
   涉及个人的策略判断属高敏内容（C-R2 必审）。
4. 沟通节奏设计：沟通计划按「宣布 → 解释 → 答疑 → 进展通报」
   四波次排布，每波次明确受众 / 渠道 / 口径 / 发言人；
   准备 FAQ 与「难回答问题清单」，口径统一。
5. 速赢设计：在变革前 90 天安排 2-3 个可见速赢，
   证明方向正确，积累变革信用。
6. 里程碑治理：变革项目按里程碑评审，
   监测采纳率 / 抵触事件 / 关键人流失三指标，
   异常即触发纠偏评审。

## 输出契约
- 变革管理方案：影响清单 + 阻力地图（ADKAR 诊断）+ 沟通计划与 FAQ。
- 关键人策略单独成册、最小范围知悉（C-R2 必审，C-R5 脱敏前置）。
- 变革涉及岗位撤销或人员安置的部分转 org-layoff-compliance 流程（C-R7）。
- 采纳率与抵触事件监测数据挂回执，进展通报只报事实不报情绪。
