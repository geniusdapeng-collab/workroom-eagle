# 融资资源对接

## 适用场景
- 企业启动融资，需要梳理投资人名单与对接策略
- 收到 TS（投资意向书）需要条款要点提示
- 融资推进缓慢，需要诊断是故事、数据还是名单问题

## 方法
1. 融资准备度先检：财务数据可经得起尽调（收入口径、
   关联交易清晰）、股权结构无重大瑕疵（代持、对赌遗留）、
   数据室（dataroom）核心材料齐备——三者不齐先补课再见人。
2. 投资人图谱：按「阶段匹配（轮次与 check size）、赛道案例、
   币种（人民币/美元）、决策风格（合伙人主导/IC 制）」
   四列建名单，分 A（高匹配）/B（备选）两档各 10-15 家；
   不匹配阶段与赛道的广撒网只会消耗市场口碑。
3. 对接节奏设计：先 B 档练手打磨叙事，再上 A 档；
   同一轮次并行推进 5-8 家制造竞争态势，
   但不群发 BP——BP 外发登记留痕，涉密数据分阶段释放。
4. TS 条款要点提示：估值与股比之外重点扫——
   清算优先权（1x 无参与分配为市场基准，超额条款提示）、
   回购/对赌触发条件与责任主体（公司回购 vs 创始人个人连带
   是天壤之别）、董事会与一票否决权范围、排他期长度。
5. 边界声明：本技能提供条款要点解读素材，不预测融资结果；
   TS/SPA 的谈判与签署必须由执业律师与财务顾问把关（C-R7）；
   融资过程中的信息披露造假（含夸大订单、刷单数据）违规即拒绝配合。

## 输出契约
- 融资准备度体检表：三项门槛达标情况 + 补课清单。
- 投资人图谱：A/B 档名单 + 匹配依据 + 对接优先级。
- 对接节奏方案：批次安排 + BP 外发登记模板。
- TS 条款要点清单：逐条标注市场基准与风险等级，留律师确认项（C-R7）。
- 估值谈判与条款签署为创始人决策，本技能不代谈、不承诺成交。
