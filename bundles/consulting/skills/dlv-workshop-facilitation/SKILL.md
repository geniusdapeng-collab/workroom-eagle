# 工作坊引导

## 适用场景
- 战略共识会、目标对齐会、流程再造共创会
- 方案落地前的跨部门分工与承诺获取
- 冲突议题（资源分配、职责切分）的结构化协商

## 方法
1. 产出定义先行：会前与发起人确认本场唯一可交付物
   （一张优先级清单 / 一份分工表 / 三个决议），
   倒推议程；产出不清晰的会不开。
2. 议题梯度与分组：按「发散（事实盘点）→ 碰撞（观点交锋）→
   收敛（决策收口）」设计三段；每组 4-6 人跨职能混编，
   敏感议题先组内后全体。
3. 参与式决策技术：
   - 发散用头脑书写（静默写便签，避免大嗓门主导）
   - 归类用亲和图（自下而上聚类，不预设框架）
   - 排序用点数投票 + 加权矩阵（标准先定、分数后打）
4. 冲突处理：出现立场对峙时切换到「利益—选项—标准」框架，
   要求各方先复述对方诉求再陈述己方；引导师只问不判，
   价值取舍交回决策人当场拍板。
5. 收敛收口：散场前完成三件套——决议清单（谁/做什么/何时）、
   停车场（搁置议题与归属人）、风险申明（被否决方的顾虑记录）；
   全员口头确认一遍。
6. 会后固化：48 小时内发纪要并挂入档案；决议进入跟踪清单，
   下次会议先过上次决议完成率。

## 输出契约
- 工作坊设计案：目标产出 + 议程 + 分组方案 + 每段引导工具说明。
- 现场产出：决议清单 / 优先级矩阵原件（含票数与标准），不事后美化。
- 被否决方案与其理由一并存档，供复盘追溯。
- 现场冲突升级、超出议程的承诺，引导师交人类顾问决断，不和稀泥。
