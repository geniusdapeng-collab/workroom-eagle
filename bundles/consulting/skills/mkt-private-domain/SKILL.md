# 私域运营体系

## 适用场景
- 公域获客成本攀升，需搭建私域承接体系
- 已有企微/社群但活跃度低、转化差
- 私域用户无分层，一条内容发所有人
- 复购率低，需设计唤醒与复购 SOP

## 方法
1. 私域引流路径设计：盘点公域触点（包裹卡/直播间/门店/公众号），
   计算各路径「扫码率 = 扫码数 / 触达数」，优先优化触点流量大但扫码率低的路径；
   引流钩子（福利/内容/服务）按毛利承受能力设上限。
2. 用户分层与标签体系：按 RFM（最近消费/频次/金额）+ 兴趣标签双维度建标签，
   标签命名规范统一（如 R-30 / F-3+ / 兴趣-母婴），标签覆盖率目标≥80%。
3. 激活 SOP：新用户入群 72 小时黄金流程（欢迎语→价值内容→首次互动→首单引导），
   每一步给出话术模板与发送时点；沉默用户按「30/60/90 天未互动」分级唤醒。
4. 内容日历：按月排期，内容配比建议「干货 40% / 互动 25% / 种草 20% / 促销 15%」，
   AI 批量拆解行业爆款内容结构（开头钩子/中段价值/结尾行动指令）生成选题库。
5. 复购与转介绍设计：复购触发点（耗材周期/换季/会员日）匹配自动化推送；
   转介绍激励机制（双向奖励）写入 SOP，所有促销信息对外发送前必审（C-R2）。

## 输出契约
- 引流路径表：触点/钩子/扫码率口径/优化优先级。
- 标签体系表：标签定义、打标规则、覆盖率口径。
- SOP 手册：72 小时激活流程 + 沉默唤醒流程，含话术模板与时点。
- 月度内容日历：日期/内容类型/选题/责任人，可执行到日。
- 福利与奖励的成本上限、促销文案对外发布必审（C-R2）；奖励力度留客户决策。
