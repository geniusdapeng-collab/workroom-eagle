# 数据资产化

## 适用场景
- 企业想响应数据要素政策，评估自身数据资源的价值与入表可能
- 拥有行业数据积累，想探索数据产品/数据服务的变现路径
- 财务部门需要数据资产入表的路径梳理与会计口径
- 拟参与数据交易所挂牌或数据质押融资，需要前期辅导

## 方法
1. 数据资源盘点：按业务域梳理数据资源清单（来源、规模、
   更新频率、质量等级、权属状况）；权属不清的数据
   （如爬取数据、客户委托加工数据）单独标注风险。
2. 合规前置审查：逐类核查数据来源合法性与授权链条——
   个人信息是否取得同意、重要数据识别、出境限制；
   合规未过的数据不得进入资产化流程（C-R9）。
3. 价值路径匹配：区分三条路径——
   - 自用提效（支撑 BI/AI，间接价值）；
   - 对外服务（数据产品/API 服务，直接收入）；
   - 入表与融资（无形资产/存货口径，需满足会计准则条件）。
   按企业数据禀赋匹配优先级，不鼓吹「万物皆可入表」。
4. 入表路径辅导：梳理成本归集口径（采集/清洗/存储/人力）、
   确权证据链与减值测试要点；入表金额与会计处理
   必须由执业会计师确认，AI 只提供准备材料清单。
5. 资产运营设计：若走对外变现，设计数据产品形态、
   定价逻辑（按调用量/按效果）、交付方式（隐私计算/
   可用不可见优先）与客户准入审核。

## 输出契约
- 数据资源清单：含权属标注与合规审查结论（C-R9）。
- 价值路径建议：三条路径匹配度评估 + 优先级排序。
- 入表准备材料清单：成本口径、确权证据、待会计师确认事项。
- 会计处理与入表金额由执业会计师裁定；数据对外提供的
  合规边界由法务决定（C-R7/C-R9），AI 不作最终结论。
