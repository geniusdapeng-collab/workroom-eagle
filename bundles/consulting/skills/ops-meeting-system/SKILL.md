# 会议体系优化

## 适用场景
- 会议泛滥，管理层一半时间在开会
- 会而不议、议而不决、决而不行
- 同一件事多个会重复讨论

## 方法
1. 会议盘点：全量会议清单化——名称 / 频率 / 时长 /
   参会人 / 产出物，计算「会议时薪成本」
   （参会人时薪合计 × 时长），用数据显化浪费，挂日程抽样回执。
2. 会议分层地图：按「决策 / 协同 / 通报 / 创意」四类重构——
   经营层（月度经营会 / 季度战略会）/ 部门层（周例会）/
   执行层（班前会 / 站会），每层定固定议程与产出物；
   纯通报类会议改异步（文档/看板）。
3. 单会纪律设计：六个一标准——一个明确目的 /
   一份会前材料（24 小时前发）/ 一个主持人 / 一个计时员 /
   一份决议清单 / 一小时上限（超时需申请）；
   决策会材料用「一页纸」模板（背景 / 选项 / 建议 / 请示）。
4. 决议追踪闭环：决议按「事项 / 责任人 / 时限 / 验证方式」
   登记入追踪表，下次会议首项议程为上期决议回顾，
   连续两次未完成自动升级到上级。
5. 参会人精简：用「决策权 / 执行责任 / 关键信息」三标准
   核定必到人员，其余改为纪要知会；
   会议规模 ≥ 8 人的决策会标红审视。
6. 试运行与度量：选 2-3 个高频会议试点一个月，
   度量会议总时长 / 决议完成率 / 参会满意度三项指标，
   达标后全面推广。

## 输出契约
- 会议体系方案：会议盘点报告（含时薪成本）+ 分层会议地图
  + 单会纪律卡 + 决议追踪表模板。
- 试点前后对比数据挂回执，效率承诺只写已验证区间。
- 会议盘点涉及个人日程数据的按 C-R5 脱敏前置，聚合呈现。
- 取消或合并会议涉及部门权责的调整交客户管理层确认（C-R2 必审）。
