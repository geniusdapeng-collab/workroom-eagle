# 情报订阅服务

## 适用场景
- 常年顾问客户需要的政策/竞对/行业持续监测
- 作为独立订阅产品向非合约客户销售
- 预警值守服务的情报供给层

## 方法
1. 情报需求校准：与客户约定三线监测清单——
   政策线（监管动态、补贴、行业标准）、
   竞对线（定价、新品、组织变动、诉讼）、
   行业线（技术趋势、资本动向、标杆案例）；
   每线 3-7 个具体信源与关键词，客户签字确认，每季度重校准。
2. 雷达采集：按日扫描信源，命中即入情报池；
   每条情报记录来源、发布时间、可信度等级（官方/媒体/传闻），
   传闻级必须标注且不与官方级混排。
3. 三问加工法（每条入选情报必须过三问）：
   对客户意味着什么（影响面）、要不要动作（紧急度）、
   和我们已知什么相关（关联档案条目）；
   过不了三问的情报只入池不上报，控制信息噪声。
4. 分层投递节拍：
   - 即时级：触发红线（重大政策、竞对重大动作）2 小时内速递
   - 周级：情报周报（三线各 Top3 + 三问解读）
   - 月级：并入月度观察报告的「环境变化」段
   节拍写入服务台账，漏报与误报都记账复盘。
5. 情报-行动闭环：速递情报若建议动作，30 天后回访采纳与结果，
   记入价值台账（情报止损/情报创收的记账入口）。
6. 质量控制：每月统计命中率（客户认为有用的比例）与误报率，
   命中率 <60% 时重校准关键词与信源。

## 输出契约
- 监测清单：三线信源与关键词，客户确认版，季度重校准记录。
- 情报条目：来源 + 可信度 + 三问解读 + 关联档案索引。
- 投递记录：即时/周/月三节拍的发送与命中反馈台账。
- 情报解读区分事实与判断；据此采取的重大经营动作由客户决策。
