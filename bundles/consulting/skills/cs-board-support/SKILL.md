# 董事会支持

## 适用场景
- 客户董事会/股东会的会前材料准备与会后跟踪
- 股东矛盾苗头期的数据与事实支持
- 常年顾问服务中的治理机制建设（议事规则、信息报送制度）

## 方法
1. 会议节拍治理：帮客户建立「年度会议日历 + 固定议程模板」——
   经营回顾（对照预算）/ 专项议题 / 决议事项三段式；
   每次会议 T-10 天启动材料准备，T-3 天材料定稿送达，
   节拍写入服务台账。
2. 材料生产线：经营数据段走文档自动化生产线（与月报同源同口径），
   专项议题段按「背景-选项-建议-风险」四段式；
   所有数字标注口径与截至日，与财务账不一致的数字不得上会。
3. 数据问答库：会前预测董事/股东高频提问（业绩、现金流、
   分红、关联交易），每问备「标准回答 + 支撑数据 + 下钻附件」；
   问答库逐次增补，历史提问命中率纳入材料质量复盘。
4. 议事规则支持：协助建立表决规则（普通/特别决议事项清单）、
   关联交易回避规则、信息报送制度（谁/何时/报什么）；
   规则文本只做专业建议稿，法律效力须客户律师审定。
5. 决议跟踪闭环：会后 48 小时内出决议清单（决议原文 +
   责任人 + 期限），下次会议首项议程为过上次决议完成率；
   长期未执行决议单列并向老板提示治理风险。
6. 敏感边界：股东矛盾议题只提供事实与数据支持，
   不站队、不评价股东个人；相关材料按敏感类目走红队质检（C-R2）。

## 输出契约
- 董事会材料包：三段式议程材料 + 数据口径页 + 问答预案。
- 决议跟踪表：历次决议的执行状态，逾期未决事项单列。
- 治理制度建议稿：标注「需律师审定」的合规提示。
- 涉股东矛盾的材料必须人类复核；表决结果与治理决策永远属于客户治理层。
