# eagle 增值服务与自动化服务化方案

> **课题**：如何用 AI 为客户企业创造更多、更高价值的服务——同时成本可控。
> **答案一句话**：把咨询师的"服务"从"人的时间"改写为"跑在客户档案上的自动化任务"——定时任务（cron 节拍）+ 事件触发（围栏/巡检）+ 夜班谷时算力 + 逐事件计量，边际成本趋零，服务密度无限。
> **版本**：v1.0 · 2026-09-02 · 对应 Bundle：`bundles/consulting/` v2.0.0

---

## 一、为什么这件事现在成立（三个结构性前提）

**前提一：档案已经在手，增值服务的边际成本趋零。**
eagle 的一企一档七分区（基本面/经营仪表盘/认知沉积/人物志/行动账本/文件库/价值台账）意味着：每一家常年顾问客户的上下文已经机器可读。传统模式下"给客户多一份情报月报"= 分析师 2 人天；eagle 模式下 = 一条夜班任务，成本以分计。**增值服务不是新生意，是已有资产的变现层。**

**前提二：WorkLoom 底座把"定时+触发+计量"做成了原生能力。**

| 底座能力 | 在增值服务中的角色 |
|---|---|
| 触发器（自研 cron + 事件触发） | 每客户独立的任务节拍器：日监测/周情报/月月报/季复盘/年报告 |
| 夜班班组（22:00-08:00 围栏内自治） | 批量情报/研究/监测任务全部谷时执行，客户无感、成本 0.2× |
| 巡检中心（只读探针 + P0/P1/P2 分级聚合） | 预警值守的感知层：指标异动/舆情/现金流红线 |
| 模型路由（L1 0.2×/L2 1×/L3 3× + 谷时再 0.2×） | 成本水闸：高频监测走 L1 谷时（0.04×），价值报告走 L3 旗舰 |
| 逐事件计量（账单=事件投影） | 每个客户每月消耗多少算力积分一目了然，定价有底 |
| C 端服务前台（多模态入站+推送箱） | 增值服务的交付通道：情报卡/预警/报告直达客户手机 |
| 技能市场（official/team/industry） | 服务产品化的载体：一套增值服务 = 一组技能 + 一组触发器 |
| 数字职场/清晨决策包 | 咨询师的管控台：所有自动化任务的结果人审后外发 |

**前提三：收费模式已被市场验证。** Harvey 的席位订阅、AlphaSense 的内容订阅、Palantir 的多年期合同——跑出来的公司全部"持续价值持续付费"（调研一 §4.1）。增值服务订阅是把咨询师从"人天计费"赎出来的船票。

## 二、增值服务产品矩阵（6 个可交付产品）

> 每个产品给出：交付内容 / 自动化机制 / 人类介入点 / 建议定价 / 成本结构。定价为建议零售价（面向中小企业客户），成本按模型路由计费估算（1 积分=1000 tokens，L2 基准 0.09 元/积分档）。

### 产品 1：鹰眼情报订阅（cs-intel-subscription + intel- 系列技能）

| 项 | 内容 |
|---|---|
| 交付 | 每周《行业情报周报》（政策雷达/竞对动态/供应链情报/招聘信号解码）+ 重大异动即时推送 |
| 自动化 | cron 每周日 22:00 夜班批量生成；intel-policy-radar / intel-competitor-tracker / intel-hiring-signal 等 8 个情报技能按客户行业装配；异动类走事件触发即时出卡 |
| 人类介入 | 周报外发前主理人 5 分钟速审（C-R2 管辖含判断的内容） |
| 定价 | ¥800-1,500/月/客户 |
| 成本 | 每周约 4-6 次 L1/L2 谷时调用 ≈ 20-40 积分/月 ≈ **2-4 元/月**；人审 20 分钟 |

### 产品 2：预警值守（cs-watchtower + 巡检中心）

| 项 | 内容 |
|---|---|
| 交付 | 7×24 指标异动监测（营收/毛利/现金流红线/舆情/竞对突袭），P1 以上 30 分钟内推送处置建议 |
| 自动化 | 巡检探针每日 07:00 + 夜班两次扫描；阈值规则行业化预置（如环比降幅>5%→P1）；P0 直接叫醒主理人 |
| 人类介入 | P0/P1 处置建议由守夜巡检起草，主理人裁决后触达客户 |
| 定价 | ¥1,500-3,000/月/客户 |
| 成本 | 每日 2-3 次 L1 谷时扫描 ≈ **3-6 元/月**；核心成本是 P1 事件的人审（月均 2-4 次×10 分钟） |

### 产品 3：月度观察报告增强版（cs-monthly-report + companion-watch）

| 项 | 内容 |
|---|---|
| 交付 | 月报（数据异动+原因判断+建议动作）+ 季度深度复盘包 |
| 自动化 | 每月 1 日 00:30 夜班生成初稿（L2），3 日主理人审定，5 日前送达（SLA 写入服务目录） |
| 人类介入 | 结论审定（Human 级）；建议动作由主理人定调 |
| 定价 | 含在常年顾问费内，或独立订阅 ¥2,000-4,000/月 |
| 成本 | 每月 2-3 次 L2 + 1 次 L3 ≈ **5-10 元/月** |

### 产品 4：年度价值报告（cs-annual-value-report + finance-keeper）

| 项 | 内容 |
|---|---|
| 交付 | 《年度价值报告》：全年服务动作量化 + 挽回/创造价值证据链（每行可下钻五元事件） |
| 自动化 | 价值台账逐事件自动记账（平时零成本），续约季前 60 天自动汇总成稿（L3 谷时） |
| 人类介入 | 叙事定调与谈判策略（Human 级） |
| 定价 | 续约转化武器，不单独收费；可将续约率提升 5-10pct |
| 成本 | 每月 1 次 L3 ≈ **10-20 元/年** |

### 产品 5：知识订阅（cs-knowledge-subscription + 技能市场 industry 层）

| 项 | 内容 |
|---|---|
| 交付 | 行业内参月刊 + 案例库 + 方法论模板库（脱敏后的跨客户知识资产） |
| 自动化 | 记忆提炼器夜班沉淀 SOP → 脱敏（industry 上架强制 desensitized=true）→ 汇编成刊 |
| 人类介入 | 每期编辑审定 + 脱敏复核（C-R5） |
| 定价 | ¥300-800/月（轻量钩子产品，获客+留存双功能） |
| 成本 | 趋零（存量知识再分发） |

### 产品 6：系统托管——为客户企业部署 WorkLoom（本课题的旗舰）

**这是最具杠杆的服务：把你的客户从"买咨询"升级为"买系统+买运营"。**

| 项 | 内容 |
|---|---|
| 交付 | 为客户企业部署一套 WorkLoom 系统（以其行业 Bundle 装配：酒店/餐饮/制造等），客户获得自己的数字员工班组；咨询师作为"托管运营商"持续运营：围栏配置、技能装配、夜班巡检、月度运营报告 |
| 自动化 | 落地向导（wizard）30 分钟装机 → Audit-Only 体检 → 影子 → 正式托管；此后夜班班组 7×24 值守，咨询师每周远程巡检一次 |
| 人类介入 | 装机期 3-5 天深度交付（高客单项目）；此后月均 2-4 小时托管 |
| 定价 | 装机费 ¥50,000-150,000（视行业 Bundle 深度）+ 托管费 ¥3,000-10,000/月 |
| 成本 | 托管期主要是客户自己的算力消耗（客户承担或计入托管费）+ 咨询师少量人审时间 |

**为什么这是咨询师的终局形态**：装机费是项目制收入的延续，托管费是常流收入的升级——而 WorkLoom 的行业 Bundle 机制让咨询师每服务一个新行业客户，就沉淀一个可复用的行业包（围栏/技能/检项），**咨询经验第一次变成了可反复销售的资产**。这正是调研一里 Palantir"经验回流产品"纪律的个体版。

## 三、成本可控的底层账（为什么敢这么定价）

以一家常年顾问客户全量订阅（情报+值守+月报+年报）为例：

| 成本项 | 月度用量 | 单价 | 月成本 |
|---|---|---|---|
| L1 轻量档（监测/分类/扫描，谷时 0.04×） | ~200 次 × 500 tokens | 0.0036 元/千 tokens | ≈ 0.4 元 |
| L2 中坚档（周报/月报/简报，谷时 0.2×） | ~30 次 × 3000 tokens | 0.018 元/千 tokens | ≈ 1.6 元 |
| L3 旗舰档（季度复盘/年报摊销） | ~2 次 × 8000 tokens | 0.27 元/千 tokens | ≈ 4.3 元 |
| 人审时间（主理人，5+20+10+30 分钟） | ~1.1 小时 | 500 元/时（机会成本） | ≈ 550 元 |
| **合计** | | | **≈ 556 元/月** |
| **对价收入** | 情报 1,200 + 值守 2,000 + 月报 3,000 | | **6,200 元/月** |
| **毛利** | | | **≈ 91%** |

算力成本只占收入的 0.1%——真正的成本是主理人 1.1 小时的人审，而这正是"人只做裁决"的设计本意。**成本可控的本质不是算力便宜，而是人类时间被精确地只花在高光时刻。**

## 四、从 0 到 1 的落地路径（90 天）

| 阶段 | 动作 | 里程碑 |
|---|---|---|
| D1-D30 | 给现有常年顾问客户免费开通"情报订阅+预警值守"（作为续约礼物），跑通自动化节拍 | 每客户每周 1 份情报周报 + 巡检规则上线 |
| D31-D60 | 把免费期产生的预警/情报案例汇编成《价值证明集》，开始对常年客户收费转化；月报增强版上线 | 首家付费增值服务客户；月报 SLA 5 日送达 |
| D61-D90 | 向 1 家最数字化接受度高的客户提案"系统托管"（装机+托管），启动首个行业 Bundle 沉淀 | 首个装机单签约；新行业 Bundle v0.1 |

**定价纪律**：增值服务只对"档案厚度 ≥3 个月"的客户销售——档案越厚服务质量越高、成本越低，这是天然的客户分层器，也是对"先签常年顾问"的引导。

## 五、风险与红线

1. **服务质量稀释**：订阅客户数 × 人审时间必须守恒——每新增 10 家订阅客户，主理人月人审增加约 11 小时，上限约 30-40 家/人（scorecard 审批通过率是扩容闸门的客观依据）。
2. **预警误报疲劳**：阈值从严起步（宁少勿滥），误报率纳入巡检检项月度回顾；客户侧推送分级（P0 电话/P1 强提醒/P2 进周报）。
3. **合规红线不变**：情报类内容含判断必审（C-R2）；涉密领域情报不碰（C-R8）；托管模式下客户数据物理隔离（local-first + RLS，C-R9）。
4. **不替代专业持牌意见**：税务/法律/审计类增值内容一律标注"建议由持牌专业人士复核"（C-R7 强制合规提示）。
